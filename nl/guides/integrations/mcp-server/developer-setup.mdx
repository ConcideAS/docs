---
title: Ontwikkelaarsconfiguratie
---

Saga is beschikbaar als een [MCP](https://modelcontextprotocol.io)-server, zodat AI-agenten en -assistenten — Claude, ChatGPT, Cursor en aangepaste agenten — uw Saga-werkruimte als hulpmiddel kunnen gebruiken. De agent kan Saga vragen stellen, projectdocumenten doorzoeken en lezen, en uw workflows uitvoeren, allemaal met uw eigen toegang.

Dit is het omgekeerde van het verbinden van externe MCP-servers met Saga. Hier *is* uw Saga-werkruimte de server waarmee andere hulpmiddelen verbinding maken.

## Voordat u begint

U hebt nodig:

- Uw **platform-URL** en een **API-sleutel**. Beide vindt u in Saga onder **Instellingen > API-sleutelbeheer**. Open de pagina, maak een sleutel aan als u er nog geen hebt, en kopieer beide waarden.
- Een MCP-client die de streambare HTTP-transport ondersteunt (Claude Desktop, Claude Code, Cursor of een aangepaste agent gebouwd op de MCP-SDK).

<Note>
Elke klant heeft zijn eigen Saga-domein, dus uw MCP-eindpunt is uw eigen platform-URL met `/api/mcp` toegevoegd. Gebruik de platform-URL die wordt getoond onder **Instellingen > API-sleutelbeheer** — raad het domein niet.
</Note>

## Een client verbinden

De meeste clients hebben alleen de eindpunt-URL en een `Authorization`-header nodig.

- **Eindpunt:** `https://<your-domain>.sagalegal.io/api/mcp`
- **Header:** `Authorization: Api-Key <your-api-key>`

Voor een client die een `.mcp.json`-bestand leest (bijvoorbeeld Claude Code), voegt u toe:

```json
{
  "mcpServers": {
    "saga": {
      "type": "http",
      "url": "https://<your-domain>.sagalegal.io/api/mcp",
      "headers": { "Authorization": "Api-Key <your-api-key>" }
    }
  }
}
```

Vervang `<your-domain>` door uw platform-URL en `<your-api-key>` door de sleutel uit **Instellingen > API-sleutelbeheer**.

<Note>
Sommige clients laten u alleen een bearer-token plakken. Gebruik in dat geval `Authorization: Bearer <your-api-key>` — Saga accepteert uw API-sleutel in beide vormen.
</Note>

## Wat de agent kan doen

Eenmaal verbonden beschikt de agent over deze hulpmiddelen:

| Hulpmiddel | Wat het doet |
|------|--------------|
| `ask_saga` | Stelt Saga een vraag en geeft het antwoord terug, net als chatten in de app. |
| `list_projects` | Geeft een lijst van uw projecten, inclusief de projecten die met u zijn gedeeld. |
| `list_project_documents` | Geeft een lijst van de documenten in een project. |
| `search_project_documents` | Doorzoekt de kennisbank van een project en geeft de meest relevante secties terug. |
| `fetch_project_document` | Geeft de volledige tekst van een document terug. |
| `ask_saga_project` | Stelt Saga een vraag binnen één project. |
| `list_assistants` | Geeft een lijst van de custom assistants die u kunt gebruiken. |
| `ask_saga_assistant` | Stelt een vraag aan Saga met een custom assistant. |
| `list_prompts` | Geeft een lijst van prompts uit uw promptbibliotheek. |
| `fetch_prompt` | Haalt de inhoud van een prompt op. |
| `get_workflow_status` | Geeft de status van een workflowrun terug. |
| `fetch_workflow_step_result` | Haalt het resultaat van een workflowstap op. |
| `submit_workflow_input` | Verstuurt tekstinvoer naar een gepauzeerde workflow. |
| `resume_workflow` | Hervat een workflow die klaar is om verder te gaan. |
| `list_workflows` | Geeft een lijst van uw workflows en de invoer die elke workflow verwacht. |
| `execute_workflow` | Voert een workflow uit met tekstinvoer en geeft het resultaat terug. |
| `list_project_folders` | Geeft de mappen en tags van de kennisbank van een project dat u kunt openen. |
| `list_project_memories` | Geeft de korte feiten die zijn opgeslagen in het geheugen van een project dat u kunt openen. |
| `list_chats` | Geeft de persoonlijke chats en projectchats die u in de app kunt openen. Chats buiten de bewaartermijn worden weggelaten. |
| `fetch_chat` | Geeft de berichten van een persoonlijke chat of projectchat die u kunt openen. Lange chats worden ingekort tot het tokenbudget. |
| `list_grid_reviews` | Geeft uw rasterbeoordelingen. Geef `project_id` mee om alleen de beoordelingen van één project te tonen. |
| `fetch_grid_review_answers` | Geeft de antwoorden van een rasterbeoordeling die u kunt openen. Grote beoordelingen worden ingekort tot het tokenbudget. |
| `search_legal_research` | Doorzoekt één juridische database waar u toegang toe hebt. Een rechtsgebied buiten uw werkruimte wordt geweigerd. |
| `list_workflow_runs` | Geeft de workflowuitvoeringen die u hebt gestart. Gebruik `get_workflow_status` om één uitvoering te lezen. |
| `fetch_workflow` | Geeft de stappen van een workflow op volgorde. Voor elke invoerstap toont het wat u moet aanleveren en of de agent dit via MCP kan aanleveren. |
| `describe_action` | Legt uit hoe u de Saga MCP-hulpmiddelen gebruikt. Zonder argumenten geeft het elk hulpmiddel en de gebruikelijke volgorde van aanroepen. Met de naam van een hulpmiddel geeft het de invoer, een voorbeeldaanroep, wat het hulpmiddel teruggeeft en wat u daarna aanroept. |

Elk hulpmiddel wordt als u uitgevoerd. De agent ziet alleen de projecten, documenten, chats, rasterbeoordelingen en workflows waartoe uw account al toegang heeft — dezelfde rechten die u in de webapp hebt.

## Beveiliging

- Behandel uw API-sleutel als een wachtwoord. Iedereen met de sleutel en uw platform-URL kan via Saga als u handelen.
- Roteer of trek de sleutel op elk moment in via **Instellingen > API-sleutelbeheer**. Intrekken stopt elke verbonden agent onmiddellijk.
- Als een sleutel mogelijk is gelekt, trek deze dan in en maak een nieuwe aan, en werk vervolgens uw clientconfiguratie bij.

## Problemen oplossen

- **De client kan geen verbinding maken of geeft 401 Unauthorized terug** — controleer of het eindpunt eindigt op `/api/mcp`, of de header `Authorization: Api-Key <your-api-key>` is en of de sleutel niet is verlopen of ingetrokken. Maak indien nodig een nieuwe sleutel aan in **Instellingen > API-sleutelbeheer**.
- **Een workflow wordt als gepauzeerd gerapporteerd**: gebruik `submit_workflow_input` voor tekstinvoer. Open Saga voor bestandsinvoer.
