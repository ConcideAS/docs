---
title: Running workflows
description: Execute workflows, provide inputs, and view results.
---

Once a workflow is built, you can run it to execute all steps in sequence. Each run processes your inputs through the defined nodes and produces results.

## Start a run

1. Open the workflow you want to run.
2. Click **Run**.
3. If the workflow has input nodes, provide the required information:
   - For **Prompt input** nodes, enter your text or instructions
   - For **Files upload** nodes, upload the documents to process
4. The workflow begins executing step by step.

## Monitor progress

As the workflow runs, you can see the progress of each step on the canvas. Completed steps show their results, and the currently executing step is highlighted.

## View results

Each action node produces output that you can review after the run completes. Depending on the node type, results may include:

- **Generated documents** from drafting nodes
- **Legal research results** from research nodes
- **Grid review tables** from grid review nodes
- **Translated content** from translate nodes
- **File outputs** from processing nodes

## Run workflows from chat

You can also attach a workflow template to a chat conversation and run it directly from within chat. Select a workflow from the chat input area, provide the required inputs, and view results in the conversation thread.
