---
title: Building workflows
description: Create visual automation flows using the drag-and-drop workflow builder.
---

The workflow builder is a visual canvas where you design automation flows by placing and connecting nodes. Each node represents a step in your workflow.

## The canvas

The builder uses a drag-and-drop interface. Add nodes from the toolbar, position them on the canvas, and connect them by dragging from one node's output to another node's input.

Your work is saved automatically as you build.

## Input nodes

Input nodes define what information the workflow needs when it runs:

| Node | Purpose |
|------|---------|
| **Prompt input** | A text field where the user provides instructions or a query at runtime |
| **Files upload** | A file upload area where the user provides documents at runtime |

## Action nodes

Action nodes perform the actual work in your workflow:

| Node | What it does |
|------|-------------|
| **Drafting** | Generate a document based on instructions and source materials |
| **Run prompt** | Send a prompt to an AI assistant with specific instructions |
| **Legal research** | Search legal databases with a query |
| **Prompt library** | Use a saved prompt from the prompt library |
| **Translate** | Translate text between languages |
| **Grid review** | Run a structured document review with defined questions |
| **Tasks** | Execute a pre-built task |
| **Logical thinking** | Apply step-by-step reasoning to a problem |
| **Code interpreter** | Run Python code for data processing or calculations |
| **Web search** | Search the internet with configurable domain filters |

## Configure a node

Click on any node to open its settings panel. Depending on the node type, you can configure:

- **Step title** — A descriptive name for the step
- **Instructions** — Specific guidance for the AI
- **Assistant** — Which AI model or custom assistant to use
- **Sources** — Which inputs or previous step outputs to use as context

## Connect nodes

Drag from a node's output handle to another node's input handle to create a connection. This defines the data flow — output from one step becomes input for the next.

You can create branching flows where one step feeds into multiple parallel steps, or merge multiple outputs into a single step.
