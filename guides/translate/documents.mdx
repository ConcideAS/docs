---
title: Document translation
---

Document translation lets you translate entire files while keeping the original layout, styles, and formatting intact.

## Supported formats

| Format | Extension |
|--------|-----------|
| Word | DOCX, DOC |
| PowerPoint | PPTX |
| Excel | XLSX |
| PDF | PDF |
| Web | HTML |
| Plain text | TXT |
| Localization | XLIFF |
| Subtitles | SRT |

## Translate a document

1. Click **Translate** in the sidebar.
2. Select the **Document** tab.
3. Choose a source language or leave it on **Auto-detect**.
4. Select the target language.
5. Upload a document using one of these methods:
   - Drag and drop a file onto the upload area
   - Click to browse and select a file
   - Import from **Epona365** (if configured)
   - Select a document from an existing **project**
6. Wait for the translation to process.
7. Download the translated document.

## Formatting preservation

The translated document maintains the original file's structure, including headings, tables, lists, images, and page layout. This means you can use the output directly without reformatting.
