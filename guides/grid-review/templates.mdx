---
title: Templates
---

Templates let you save a set of questions and reuse them across projects. Instead of defining the same questions every time, create a template once and apply it whenever you start a new grid review.

## Use a template

When creating a new grid review, choose **From template** instead of starting blank:

1. Browse available templates in three categories: **Personal**, **Organization**, and **SagaLab**.
2. Preview the template to see its questions and instructions.
3. Select the template and click **Create**.

The grid is created with the template's questions already defined. You can modify the questions after creation without affecting the original template.

## Save a grid as a template

To save your current grid's questions as a reusable template:

1. Open the grid review.
2. Click the save as template option.
3. Give the template a name and description.
4. Save.

The template appears in your **Personal** templates.

## Template categories

| Category | Who can see it | Who manages it |
|----------|---------------|---------------|
| **Personal** | Only you | You |
| **Organization** | Everyone in your organization | Admins (via [admin panel](/guides/admin/libraries)) |
| **SagaLab** | Everyone | Saga (curated templates) |

## Share a template with your organization

If you've created a personal template that would benefit your team, you can request to make it available organization-wide. Click **Request to make public** on the template, and an administrator can review and approve it.

## Edit a template

You can edit a template's questions before using it. Click **Edit** in the template preview to modify questions, then choose **Save & Use** to create a grid from the edited version.
