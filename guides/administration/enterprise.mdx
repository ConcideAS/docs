title: Enterprise
---

Enterprise workspaces include automatic user provisioning and the full admin panel for firm-wide management.

## User provisioning

Enterprise accounts use automatic user provisioning. User accounts are created and updated automatically, so admins do not need to add each new user manually.

## Workspace features

Enterprise workspaces include the full admin panel:

- **Centralized user management** — manage roles, deactivation, and reactivation
- **Integrations** — configure SharePoint, Epona365, and MCP tools
- **Firm-wide document styling** — apply custom fonts, headers, and footers
- **Organizational sources** — manage shared knowledge bases
- **Shared libraries** — manage prompts, workflows, and grid review templates
- **Custom assistants** — configure assistants for firm workflows
- **Usage metrics** — review usage data and export users to Excel
