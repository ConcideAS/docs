# Overview

Enterprise is Saga's plan for firms that need centralized, firm-wide management. Users are provisioned automatically, admins get the full admin panel, and shared resources like organizational sources, libraries, and custom assistants can be managed for the whole firm from one place.

## User provisioning

Enterprise accounts use automatic user provisioning. User accounts are created and updated automatically, so admins do not need to add each new user manually.

## Workspace features

Enterprise workspaces include the full admin panel:

- **Centralized user management.** Manage roles, deactivation, and reactivation.
- **Integrations.** Configure SharePoint, Epona365, NetDocuments, Dillien, and MCP tools.
- **[Firm-wide document styling](/guides/administration/document-styling).** Apply custom fonts, headers, and footers to Word and Excel exports.
- **Organizational sources.** Manage shared knowledge bases available to everyone in the firm.
- **Shared libraries.** Manage firm-wide prompts, workflows, and grid review templates.
- **Custom assistants.** Configure assistants for firm workflows.
- **Usage metrics.** Review usage data and export users to Excel.

For how each section works, see the [admin panel](/guides/administration/admin-panel) guide.

## Enterprise or Solo?

Choose Enterprise when you need automatic provisioning, more than 5 users, or firm-wide governance of sources, styling, and libraries. [Solo](/guides/administration/solo) covers small teams with self-serve billing and manual user management. Contact [support@sagalegal.io](mailto:support@sagalegal.io) to move from Solo to Enterprise.
