---
title: Document styling
description: Configure how Saga-generated Word and Excel exports follow your firm's document style.
---

<Note>
Document styling is an [Enterprise](/guides/administration/enterprise) feature. Each firm runs its own instance (for example `yourfirm.sagalegal.io`), and document styling is configured in that instance's admin panel.
</Note>

Document styling is an admin setting for Word and Excel exports generated by Saga. Use it when your firm wants drafts, summaries, memos, and downloaded tables to follow the same document style.

Only admins can configure document styling. Users see the result when they export generated content after the settings are saved.

## Word export styling

Word export styling can control:

- Body font, size, color, and line spacing
- Heading fonts, sizes, colors, and weight
- Page size, orientation, margins, indentation, and spacing
- Header and footer text
- Page number placement and alignment
- Header and footer logos

These settings apply to new exports. They do not change files that were already downloaded, and they do not change documents that users upload to a project or knowledge base.

### Upload a Word reference document

Use a reference document when you already have a Word file that represents your firm's style.

1. Open **Admin panel**.
2. Go to **Document Styling > Word Export**.
3. Upload a `.docx` reference document.
4. Review the extracted style in the preview.
5. Adjust any fields manually if needed.
6. Click **Save changes**.

Saga reads the style from the reference document and uses it as the starting point for future Word exports.

<Tip>
Use a clean reference document with the styles you want Saga to copy. Avoid documents with tracked changes, inconsistent headings, or unusual one-off formatting.
</Tip>

### Adjust Word styles manually

You can fine-tune the extracted style before saving. You can also configure the style manually without uploading a reference document.

Use the manual editor when you need to change details such as margins, heading sizes, page numbers, header text, or footer text without preparing a new Word file.

### Add header and footer logos

You can upload logos for the header or footer. Use this for firm branding, letterheads, or other standard export layouts.

If an exported document does not show the logo you expected, check that the logo was saved in the correct header or footer slot, then export the document again.

## Excel export styling

Excel export styling controls the appearance of tables that users download from Saga. You can configure fonts, text and fill colors, zebra striping, row height, column width, alignment, text wrapping, and borders.

### Upload an Excel reference workbook

Use a reference workbook when you already have an Excel file that represents your firm's table style.

1. Open **Admin panel**.
2. Go to **Document Styling > Excel Export**.
3. Click **Upload a reference workbook** and select an `.xlsx` file up to 25 MB.
4. Review the extracted settings and preview.
5. Adjust any fields manually if needed.
6. Click **Save changes**.

Saga extracts fonts, colors, dimensions, alignment, and borders from the workbook. New table downloads use the saved firm-wide style.

### Adjust Excel styles manually

You can configure Excel styling without a reference workbook, or adjust the extracted values before saving. Use the manual editor to style heading cells and data cells separately, then review the result in the live preview.

If you want to discard manual changes, select **Reset to Reference Document**. To remove the reference workbook and return to Saga's default styling, select **Reset to Saga Defaults**.

## When changes take effect

Changes apply to new exports after you save them. Existing exported files are not updated.

If a user downloaded a document or table before the settings changed, they need to export it again to get the updated styling.

## Test the style

Before you rely on the style for client-facing work, test each export type you configured.

For Word styling, export a short document from chat and review the body text, headings, margins, headers, footers, page numbers, and logos in Word.

For Excel styling, download an AI-generated table and review the heading cells, data cells, dimensions, alignment, wrapping, zebra striping, and borders in Excel.

If anything looks wrong, return to **Admin panel > Document Styling**, open the relevant export tab, update the setting, save, and export again.
