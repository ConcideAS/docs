A project is your workspace for a case, transaction, or any body of work. It keeps documents, AI conversations, and grid reviews together in one place, so the AI always has the right context when you ask questions or run analyses.

<Tip>
Create a project for a due diligence matter to keep all related contracts, AI conversations, and review grids in one place.
</Tip>

## Create a project

1. Click **Projects** in the sidebar.
2. Click **New project**.
3. Enter a name for the project — for example, the case name or client reference.
4. Optionally add a description, default assistant, or custom instructions that apply to all AI interactions within the project.

## Project structure

Every project has three tabs:

| Tab | Purpose |
|-----|---------|
| **Knowledge base** | Upload and organize documents that the AI uses as context |
| **Chat** | AI conversations scoped to this project's documents |
| **Grid review** | Structured document reviews with AI-generated answers |

## Work within a project

Once your project has documents in its knowledge base, you can:

- **Ask questions in chat** — The AI draws on your uploaded documents to answer. Responses include citations you can click to verify.
- **Run a grid review** — Define a set of questions and let the AI analyze each document against them, producing a structured table of results.
- **Share with colleagues** — Invite other users and assign permission levels to collaborate on the same project.
