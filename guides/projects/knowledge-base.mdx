title: Knowledge base

The knowledge base is the document library inside a project. Every file you upload is processed by Saga — the text is extracted, broken into passages, and stored so the AI can find the most relevant parts when you ask a question. This is what makes Saga's answers grounded in your actual documents rather than general knowledge.

## How the AI searches your documents

When you ask a question in a project chat, the AI has intelligent access to every active document in the knowledge base. Rather than loading all documents upfront, Saga equips the AI with two specialized search capabilities that it uses on demand:

- **Document search** — the AI searches across all project documents at once to find the most relevant passages. This is what the AI uses by default for most questions: summaries, topical lookups, comparisons across files, or any question that could touch multiple documents.
- **Full document fetch** — the AI retrieves the complete content of a specific named document. This is used for tasks that require the entire text, such as a clause-by-clause review, a full summary of one contract, or extracting every occurrence of a term from a single file.

The AI chooses the right approach automatically. For a broad question like "What are the payment terms across these agreements?", it searches all documents. For "Summarize the NDA with Acme Corp", it fetches that specific document in full. For a deep side-by-side comparison, it may fetch multiple documents individually.

<Tip>
You don't need to tell the AI how to search. It sees the names of all active documents in the knowledge base and decides the best retrieval strategy for each question. If it can't find what you're looking for, try using the exact document name or a specific term from the text.
</Tip>

## Add documents

Drag and drop files or folders directly into the knowledge base panel, or click **Upload** to browse your computer. If your organization has SharePoint or Epona365 configured, you can import files from those services as well.

Saga supports a wide range of file types:

| Category      | Formats                             |
| ------------- | ----------------------------------- |
| Documents     | PDF, DOC, DOCX, TXT, HTML, CSV, ODT |
| Spreadsheets  | XLS, XLSX, ODS                      |
| Presentations | PPTX                                |
| Email         | EML, MSG                            |
| Images        | PNG, JPG, JPEG, GIF, WEBP, TIFF     |

The maximum file size is 1 GB. A project can hold up to 1,000 documents.

After upload, each file goes through processing before it's available to the AI. You can keep working while this happens — documents become available automatically as they're ready. If a file fails to process, you can retry it from its action menu.

## Active and inactive documents

Every document has an active/inactive toggle. Only active documents are used as context by the AI. Inactive documents stay in the knowledge base but are excluded from chat and grid review.

This is useful when you want to narrow the AI's focus to a specific subset of files — for example, during a phase of a matter where only certain contracts are relevant.

## Folders and tags

You can organize documents with folders and color-coded tags.

**Folders** let you replicate your existing file structure. Create nested folders, drag documents between them, and download an entire folder as a ZIP when you need to share files outside Saga. Your folder expand/collapse state is saved automatically and persists across page refreshes, so you always return to the view you left off at.

**Tags** work across folders. Assign a tag to a document, give it a color, and use the tag filter to show only documents with that label. Tags are useful for marking document types, review status, or anything else that cuts across your folder structure.

## Document actions

Each document has an action menu where you can rename it, move it to a different folder, manage its tags, download it, retry processing, or delete it. You can also select multiple documents at once for bulk download or deletion.

When selecting documents, folder checkboxes show a partial-selection indicator if only some files inside are selected, making it easier to see exactly what's included. Toggling a single document's active state shows a loading indicator only on that item, so you can continue working with the rest of the list.
