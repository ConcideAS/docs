---
title: Knowledge base
description: Upload, organize, and manage documents in your project's knowledge base.
---

The knowledge base is where you store the documents that power your project. Every file you upload becomes available as context for AI chat and grid reviews within that project.

## Upload documents

You can add documents to the knowledge base in several ways:

- **Drag and drop** files or folders directly onto the knowledge base area
- **Click to browse** and select files from your computer
- **Upload folders** to preserve your existing directory structure
- **Import from SharePoint or Epona365** if your organization has these integrations configured

## Supported file types

| Category | Formats |
|----------|---------|
| Documents | PDF, DOC, DOCX, TXT, HTML, CSV, ODT |
| Spreadsheets | XLS, XLSX, ODS |
| Presentations | PPTX |
| Email | EML, MSG |
| Images | PNG, JPG, JPEG, GIF, WEBP, TIFF |

The maximum file size is 1 GB per file.

## Organize with folders

Create folders to keep your knowledge base structured:

1. Click **New folder** in the knowledge base toolbar.
2. Name the folder.
3. Drag documents into folders, or move them using the document action menu.

You can nest folders, rename them, and download an entire folder as a ZIP file.

## Tag documents

Tags help you categorize and filter documents across folders:

1. Select a document and choose **Add tag** from the action menu.
2. Create a new tag or select an existing one.
3. Assign a color to make tags visually distinct.

Use the tag filter in the knowledge base toolbar to show only documents with a specific tag.

## Manage documents

Each document in the knowledge base supports the following actions:

- **Rename** — Update the display name
- **Move** — Move to a different folder
- **Tags** — Add or remove tags
- **Active/inactive** — Toggle whether the document is included as AI context. Inactive documents remain in the knowledge base but are excluded from chat and grid review
- **Delete** — Permanently remove the document
- **Retry** — Re-process a document that failed during upload

## Document processing

After upload, Saga processes each document to make it searchable and available for AI analysis. You can see the processing status next to each file. Once processing completes, the document is ready to use in chat and grid reviews.

<Tip>
For large uploads, you can continue working while documents process in the background. The knowledge base updates automatically as each file becomes ready.
</Tip>
