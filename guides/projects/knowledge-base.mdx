---
title: Knowledge base
---

The knowledge base stores the documents that power your project. Every file you add becomes available as context for AI chat and grid reviews within that project. It lives in the right panel of the **Chat** tab inside each project.

## Upload documents

You can add documents to the knowledge base in several ways:

- **Drag and drop** files or folders directly onto the knowledge base area
- Click **Upload** and choose **Upload files** to select one or more files from your computer
- Click **Upload** and choose **Upload folders** to upload an entire folder — the existing folder structure is preserved
- Click **Upload** and choose **Import from SharePoint** or **Import from Epona365** if your organization has these integrations configured

A project can hold up to **1,000 documents**.

## Supported file types

| Category | Formats |
|----------|---------|
| Documents | PDF, DOC, DOCX, TXT, HTML, CSV, ODT |
| Spreadsheets | XLS, XLSX, ODS |
| Presentations | PPTX |
| Email | EML, MSG |
| Images | PNG, JPG, JPEG, GIF, WEBP, TIFF |

The maximum file size is 1 GB per file.

If you drop files in an unsupported format, a dialog lists the invalid file names so you can review them.

## Document processing

After upload, Saga processes each file to make it searchable and available for AI analysis. A progress indicator appears next to each file during processing.

| Status | Meaning |
|--------|---------|
| Queued | Waiting to start processing |
| Uploading | File is being transferred |
| Pending | Processing in progress |
| Retrying | Processing is being reattempted |
| Ready | Processing complete — available for chat and grid review |
| Failed | Processing failed — use **Retry** to try again |

<Note>
You can continue working while documents process in the background. The knowledge base updates automatically as each file becomes ready.
</Note>

## Active and inactive documents

Each document has an active/inactive toggle. Active documents are included as AI context in chat and grid reviews. Inactive documents remain in the knowledge base but are excluded from AI interactions.

Use this to temporarily remove a document from context without deleting it — for example, to focus the AI on a specific subset of files.

## Organize with folders

Create folders to keep your knowledge base structured:

1. Click the **folder** icon in the knowledge base toolbar.
2. Name the folder.
3. Drag documents into folders, or use **Move to** in the document action menu.

Folders can be nested — you can create subfolders within folders. You can also rename, download, and delete folders. Deleting a folder asks you to confirm how many subfolders and documents will be affected.

## Search and filter

- Use the **search bar** in the knowledge base toolbar to filter documents and folders by name.
- Use the **tag filter** to show only documents with a specific tag.

## Tag documents

Tags help you categorize and filter documents:

1. Open the **...** menu for a document and select **Manage tags**.
2. Create a new tag, choose a color, or select an existing tag.
3. Confirm to apply.

Use the tag filter in the knowledge base toolbar to show only documents with a specific tag.

## Duplicate detection

If you upload a file with the same name as one already in the knowledge base, a dialog lists the duplicates and asks whether to upload anyway or cancel.

## Document actions

Each document supports the following actions from its **...** menu:

| Action | Description |
|--------|-------------|
| **Download** | Download the file to your computer |
| **Rename** | Edit the document's display name inline |
| **Move to** | Move the document to a different folder |
| **Manage tags** | Add or remove tags |
| **Retry** | Re-process a document that has a Failed status |
| **Delete** | Permanently remove the document from the project |

## Bulk actions

Select multiple documents using the checkboxes to:

- **Download** all selected files at once
- **Delete** all selected files with a single confirmation

The toolbar shows how many items are selected (for example, "3 of 12 selected") and a **Select all** checkbox to select everything in the current view.

## Folder actions

Each folder's **...** menu provides:

| Action | Description |
|--------|-------------|
| **Download folder contents** | Download all files in the folder as a ZIP |
| **Move to** | Move the entire folder to another location or to the root |
| **Create subfolder** | Add a nested folder inside this folder |
| **Rename** | Edit the folder name inline |
| **Delete folder** | Remove the folder and all its contents |
