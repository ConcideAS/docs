---
title: Context and sources
---

The quality of AI responses depends on the context it has access to. Saga gives you several ways to provide relevant information to the AI during a conversation.

## Attach files to a message

Drag and drop files onto the chat input or click the attachment button to add files directly to a message. These files are used as context for that specific conversation.

If your organization has SharePoint or Epona365 integrations configured, you can also import files from those services using their document pickers.

## Project knowledge base

When you use chat inside a [project](/guides/projects), the AI automatically has access to all active documents in the project's knowledge base. You don't need to attach files individually — the AI searches across the full knowledge base to find relevant passages.

## Organizational sources

Organizational sources are knowledge bases set up by your admin that are available across all projects and chats. To include organizational sources in your conversation:

1. Click the organizational sources option in the chat input area.
2. Select which sources to include.

The AI then uses those sources alongside any other context you've provided.

## Web search

Toggle web search to let the AI search the internet for additional context beyond your documents. A banner appears in the chat when web search is active.

<Note>
Web search queries are sent to external search engines. Use this feature only when you're comfortable with the query content being transmitted externally.
</Note>

## URL extraction

Paste a URL into the chat, and Saga automatically extracts and processes the page content. The AI can then reference that content in its response.

## System prompt

Set a custom system prompt to give the AI specific instructions for the conversation — for example, "Always respond in bullet points" or "Focus only on Norwegian contract law." Access the system prompt from the badge in the chat input area.

The system prompt applies to the current conversation only. To set a default system prompt for all your conversations, update it in your [settings](/guides/account/settings).
