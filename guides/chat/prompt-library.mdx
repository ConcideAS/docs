---
title: Prompt library
---

The prompt library lets you save prompts that you use frequently and access them in any conversation. Your organization's administrators can also create shared prompts available to all users.

## Save a prompt from chat

After sending a message that you'd like to reuse:

1. Hover over the message.
2. Click the **Save to Prompt Library** action.
3. Give the prompt a name and save.

The prompt is added to your personal prompt library.

## Use a saved prompt

1. Open the prompt library from the chat input area.
2. Browse or search for the prompt you want.
3. Click a prompt to insert it into the message input.

## Manage your prompts

From the prompt library, you can:

- **Search** prompts by name or content
- **Favorite** prompts for quick access
- **Edit** the prompt text or name
- **Duplicate** a prompt to create a variation
- **Delete** prompts you no longer need

## Organization-wide prompts

Administrators can create shared prompts that appear in every user's prompt library. These are managed from the [admin panel](/guides/admin/libraries) under **Libraries > Prompts**.

<Tip>
Save prompts for tasks you repeat across multiple cases — for example, a standard contract review checklist or a due diligence question template.
</Tip>
