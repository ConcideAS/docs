---
title: Prompt library
---

The prompt library lets you save instructions you use repeatedly and apply them to any conversation in one click. Instead of rewriting the same contract review checklist or due diligence framework every time, you write it once, save it, and reuse it across matters.

Organization-wide prompts take this further. Your admin or Saga's legal engineers can publish prompts that appear in every user's library — which is how a firm standardizes its approach to recurring work. Everyone starts from the same instructions, and the output stays consistent.

## How to use it

Open the prompt library from the toolbar in the chat input area. Browse, search, or pick from your favorites. When you select a prompt, it loads into your message input — you can send it as-is or adjust it for the specific situation before sending.

There are several ways to add prompts to your library. You can create one from scratch directly inside the prompt library, save a message you've already written in chat by hovering over it and clicking **Save to Prompt Library**, or duplicate any organization or Saga Lab prompt into your personal collection if you want to customize it.

## Where prompts come from

Prompts are organized into three pools:

- **Personal** — prompts you've created, visible only to you
- **Organization** — prompts published by your admin, available to everyone in your firm
- **Saga Lab** — curated prompts provided by the Saga team

You can filter prompts by language, prompt type, or matter type when your library grows large enough that browsing isn't practical.

## Prompt library in the Word add-in

Your prompt library is also available in the [Saga Word add-in](/guides/integrations/word-add-in). You can browse and apply the same prompts — personal, organization, and Saga Lab — directly from the Word sidebar, with the same language filtering you have in the web app.
