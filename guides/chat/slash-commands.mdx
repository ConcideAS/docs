---
title: Slash commands
---

Slash commands are shortcuts for common tasks. Type a forward slash `/` in the chat input to see available commands.

## Available commands

| Command | What it does |
|---------|-------------|
| `/summarize` | Generate a concise summary of the provided text or document |
| `/anonymize` | Remove or replace personal identifiers and sensitive information |
| `/proofread` | Check text for grammar, spelling, and style improvements |
| `/compare` | Compare two texts or document sections and highlight differences |

## How to use slash commands

1. Type `/` in the chat input.
2. Select a command from the dropdown or type the command name.
3. Provide the text or attach the documents the command should work with.
4. Press **Enter** to run the command.

The AI processes the command and returns the result as a chat message, which you can copy, export, or continue working with.
