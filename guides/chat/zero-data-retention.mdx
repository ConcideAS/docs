---
title: Zero data retention
description: Use chat without storing any conversation data on Saga's servers.
---

Zero data retention (ZDR) mode lets you have AI conversations where no data is persisted on the server. Messages, documents, and responses stay in your browser session only and are discarded when you close or navigate away.

## When to use ZDR mode

ZDR mode is designed for situations where you need to work with highly sensitive content and want to ensure that no conversation data is stored server-side. This can be relevant for privileged communications or materials with strict confidentiality requirements.

## How ZDR mode works

- **No server storage** — Messages and responses are not saved to Saga's servers
- **No chat history** — ZDR conversations don't appear in your chat history
- **Client-side only** — All conversation context stays in your browser
- **Session-bound** — Closing the tab or navigating away permanently discards the conversation

## Start a ZDR conversation

ZDR mode is available both as a standalone chat and within projects. When ZDR mode is active, a banner appears at the top of the chat indicating that no data is being retained.

## Feature differences in ZDR mode

Some features are unavailable in ZDR mode because they require server-side storage:

| Feature | Available in ZDR |
|---------|-----------------|
| AI chat with citations | Yes |
| File attachments | Yes |
| Legal research | Yes |
| Organizational sources | Yes |
| Knowledge base context | Yes |
| Chat history | No |
| Message feedback (like/dislike) | No |
| Delete individual messages | No |
| AI-generated documents | Client-side only |
