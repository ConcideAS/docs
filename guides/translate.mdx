---
title: Translate
---

Saga includes built-in translation powered by DeepL. You can translate text or entire documents between 30+ languages — including regional variants like British and American English or Brazilian and European Portuguese — without leaving the platform. Click **Translation** in the sidebar to open it.

## Text

Paste or type text in the source area, pick your target language, and the translation appears on the right. The source language is auto-detected, or you can set it manually. Click **Copy** to grab the result.

## Documents

Drag and drop files into the source area, or click to browse your computer. You can also pull documents from a project's knowledge base or Epona365. The translated files appear as downloadable chips in the output area. Click to download individually, or use **Download All** when you've translated a batch. {/* pragma: allowlist secret */}

While a document translates, its row shows how much time is left, based on the estimate from DeepL. If the translation runs past that estimate, the row shows **Taking longer than expected. Still translating.**

If a translation fails, the row shows **Couldn't translate**. Click **Retry** to translate the same file again with the same languages. You do not need to upload the file again.

To save a translated file in a project, click the **Add to project** icon on its row and choose a project or a folder. To add every finished translation at once, click **Add All to Project**. The list shows only projects that you can edit, and you can click **Create New Project** to add a new one. For example, you can translate a set of exhibits and put them straight into the knowledge base of the matter.

Supported formats: **DOCX**, **PPTX**, **XLSX**, **PDF**, **HTML**, **TXT**, **XLF/XLIFF**, and **SRT**. Formatting is preserved during translation.

| Format | Size limit |
|--------|-----------|
| DOCX, PPTX, XLSX, PDF | 30 MB |
| XLF, XLIFF | 10 MB |
| HTML | 5 MB |
| TXT, SRT | 1 MB |

<Note>
Translated documents are available for download once. After you download a file, it's removed from the list and can't be re-downloaded — so save it where you need it.
</Note>
