---
title: Libraries
---

Libraries let administrators create and manage shared resources that are available to all users. Access libraries from **Admin panel > Libraries**.

## Prompt library

Create shared prompts that appear in every user's prompt library:

1. Go to **Libraries > Prompts**.
2. Click **New prompt**.
3. Write the prompt template and give it a descriptive name.
4. Save — it becomes available to all users immediately.

You can also review and approve prompts that users have requested to share.

## Grid review templates

Create reusable question sets for grid reviews:

1. Go to **Libraries > Grid review templates**.
2. Click **New template**.
3. Define the questions (columns) and their types.
4. Add an optional instruction.
5. Save — users can select the template when creating new grid reviews.

## Custom assistants

Build assistants with specific instructions and behaviors:

1. Go to **Libraries > Custom assistants**.
2. Click **New assistant**.
3. Configure the assistant's name, instructions, and behavior.
4. Save — it appears in the assistant selector for all users.

Custom assistants are useful for standardizing how AI handles specific task types across your firm — for example, a "Contract Reviewer" assistant with detailed instructions on what to look for.

## Workflows

Manage shared workflow templates:

1. Go to **Libraries > Workflows**.
2. Create or import workflows.
3. Published workflows appear in every user's workflow library.

You can also review and approve workflows that users have requested to share with the organization.
