---
title: User management
---

Manage your organization's users from **Admin panel > Organization > Users**. Here you can invite new team members, assign roles, and control access.

## Invite users

1. Go to **Organization > Users**.
2. Click **Invite user**.
3. Enter the user's email address.
4. Assign a role.
5. Send the invitation.

The user receives an email with instructions to sign in.

## Roles

Assign roles to control what each user can access:

- **User** — Standard access to all Saga features
- **Admin** — Full access plus the admin panel and organization management
- **Content admin** — Can manage shared libraries (prompts, templates, assistants, workflows) and organizational sources

## Remove a user

To remove a user from the organization:

1. Find the user in the user list.
2. Click the user actions menu.
3. Select **Remove**.

Removed users immediately lose access to Saga and all shared projects.

## Reactivate a user

Previously removed users can be reactivated from the user management page, restoring their access without requiring a new invitation.
