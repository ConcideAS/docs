---
title: Workspace settings
description: Configure AI models, defaults, and organization-wide policies for your Saga instance.
---

Workspace settings let you control how Saga behaves for all users in your organization. Access these from **Admin panel > Preferences > Workspace settings**.

## Default assistant

Set the AI model or custom assistant that is used by default when users start a new conversation. Individual users can override this in their personal [settings](/guides/account/settings).

## Enabled models

Choose which AI models are available to users. Disabled models won't appear in the assistant selector.

## Default language

Set the default interface language for your organization. Users can change their own language preference in their settings.

## Project types

Define project types that users can select when creating a new project. This helps standardize how projects are categorized across the organization.

## Document limit

Set the maximum number of documents that can be uploaded to a single project's knowledge base.

## Prompt library languages

Configure which languages are available for prompt library content.

## Legal research

Configure which legal research databases are enabled for your organization and their settings.

## AI policy

Set an organization-wide AI usage policy that is displayed to all users. Use this to communicate guidelines, limitations, or compliance requirements around AI use within your firm.
