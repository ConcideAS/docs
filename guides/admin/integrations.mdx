---
title: Integrations
---

Saga integrates with external tools and services to bring your existing documents and workflows into the platform. Configure integrations from **Admin panel > Organization > Integrations**.

## Epona365

Connect Saga with Epona365 to enable document import from your DMS:

1. Go to **Integrations > Epona365**.
2. Enter your Epona365 base URL.
3. Configure the SharePoint site connection.
4. Save.

Once configured, users can import documents from Epona365 when uploading to project knowledge bases, attaching files in chat, or using document translation.

## SharePoint

Connect to SharePoint for direct file access:

1. Go to **Integrations > SharePoint**.
2. Enter your SharePoint base URL.
3. Save.

Users can then browse and import SharePoint files into Saga.

## Translate service

Toggle the translation feature on or off for your organization. When disabled, the Translate option is hidden from the sidebar for all users.

## MCP servers

Configure Model Context Protocol (MCP) servers for advanced integrations. MCP allows Saga to connect to external tools and data sources that extend the AI's capabilities.

1. Go to **Organization > MCP servers**.
2. Click **Add server**.
3. Configure the server connection, including OAuth settings if required.
4. Save.

Users can connect their personal accounts to configured MCP servers from their [settings](/guides/account/settings).
