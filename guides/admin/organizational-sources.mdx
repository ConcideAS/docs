---
title: Organizational sources
description: Create shared knowledge bases that are available across all projects and chats.
---

Organizational sources are knowledge bases managed at the organization level. Unlike project knowledge bases, which are scoped to a single project, organizational sources are available to all users across all projects and chats.

## When to use organizational sources

Use organizational sources for reference materials that apply broadly across your organization — for example, internal policies, standard templates, regulatory guidance, or frequently referenced legislation.

## Create an organizational source

1. Go to **Admin panel > Organization > Organizational sources**.
2. Click **New source**.
3. Enter a name and description.
4. Save.

## Upload documents

After creating a source, upload documents to it the same way you would with a project knowledge base:

- Drag and drop files or folders
- Click to browse and select files
- Organize with folders and tags

<Note>
Only administrators and content administrators can create and manage organizational sources. All users can access the content in chat and project conversations.
</Note>

## How users access organizational sources

Users can select organizational sources as context in any chat conversation. See [Context and sources](/guides/chat/context-and-sources) for details on how to include organizational sources in a conversation.

## Difference from project knowledge bases

| Feature | Project knowledge base | Organizational source |
|---------|----------------------|----------------------|
| **Scope** | Single project | Entire organization |
| **Who can upload** | Project members with edit access | Admins and content admins |
| **Who can use as context** | Project members | All users |
| **Active/inactive toggle** | Yes | No |
