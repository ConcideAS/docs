---
title: Settings
---

Access your personal settings by clicking your profile avatar in the sidebar.

## Profile

Update your display name and profile avatar. Your name appears in shared projects and chat conversations.

## Default assistant

Choose the AI model or custom assistant that is used by default when you start a new conversation. This overrides the workspace default set by your administrator.

## System prompt

Set a default system prompt that applies to all your new conversations. Use this for standing instructions — for example, "Always respond in Norwegian" or "Use formal legal language."

## Keyboard shortcuts

Configure how the **Enter** and **Shift+Enter** keys behave in the chat input:

| Option | Behavior |
|--------|----------|
| **Enter to send** | Enter sends the message, Shift+Enter adds a new line |
| **Shift+Enter to send** | Shift+Enter sends the message, Enter adds a new line |

## Language

Change the interface language. Saga supports over 10 languages including English, Norwegian, Dutch, German, French, Spanish, Italian, Portuguese, Turkish, Polish, and Swedish.

## Theme

Switch between **light** and **dark** mode, or follow your system preference.

## API key

Generate an API key for programmatic access to Saga:

1. Go to your settings.
2. Click **Create API key**.
3. Copy the key — it's only shown once.

You can rotate or delete your API key at any time. The platform URL is also displayed here for API configuration.

## MCP integrations

If your organization has MCP servers configured, you can connect your personal account to them from settings. This may require OAuth authentication depending on the server configuration.
