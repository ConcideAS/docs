title: Troubleshooting
---

If you run into issues while using Saga, check the solutions below or reach out to our support team.

## Common issues

### Documents stuck in processing

If a document shows a processing status for an extended period:

1. Open the project's knowledge base.
2. Find the document and click the action menu.
3. Select **Retry** to re-process the document.

If the issue persists, the file may be corrupted or in an unsupported format. Try re-saving the document and uploading again.

### Chat not responding

If the AI stops responding mid-conversation:

- Check your internet connection
- Try refreshing the page
- Start a new conversation if the issue continues

Network interruptions during streaming are handled automatically — Saga attempts to recover the connection.

### Translation service unavailable

The translate feature depends on an external service. If the status indicator shows the service is offline, wait a moment and try again. Saga automatically retries failed translations when the connection is restored.

### Can't access admin panel

The admin panel is only visible to users with an administrator role. If you need admin access, ask your organization's current administrator to update your role.

## Submit feedback

To report a bug or request a feature:

1. Click the **Feedback** option in the sidebar.
2. Select **Bug** or **Feature request**.
3. Set a priority level.
4. Describe the issue or suggestion.
5. Optionally attach screenshots or screen recordings.
6. Submit.

## Contact support

For issues not covered here, reach out to the Saga support team at [support@saga.com](mailto:support@saga.com).
