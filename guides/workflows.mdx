---

Workflows let you create visual, node-based automation flows. Chain together steps like document analysis, research, and content generation to automate repetitive tasks.

## Open workflows

Click **Workflows** in the sidebar to access the workflow builder.

## Create a workflow

1. Click **New workflow**.
2. Drag nodes from the node palette onto the canvas.
3. Connect nodes by dragging from one node's output to another's input.
4. Configure each node by clicking it and setting its parameters.
5. Click **Run** to execute the workflow.

## Workflow library

Browse pre-built workflows in the **Workflow library**. These cover common legal tasks and can be used as-is or customized to fit your needs.

Admins can create and share workflows across the organization. See [Admin panel](/guides/admin-panel) for details.

## Run a workflow

1. Open the workflow you want to run.
2. Provide any required inputs (documents, text, parameters).
3. Click **Run**.
4. Monitor progress as each node executes in sequence.

<Tip>
Save workflows you use frequently to the library so your team can reuse them.
</Tip>
