Workflows let you create visual, node-based automation flows. Chain together steps like document analysis, research, translation, and content generation to automate repetitive tasks that would normally require switching between multiple tools.

<Tip>
Build a workflow that takes a set of contracts, extracts key terms with grid review, researches relevant case law, and drafts a summary memo — all in a single automated sequence.
</Tip>

## How workflows work

A workflow is a sequence of connected steps displayed on a visual canvas. Each step is a **node** that performs a specific action — generating text, running a search, translating content, or processing documents. You connect nodes to define the order of operations and how data flows from one step to the next.

## Get started

Click **Workflows** in the sidebar to access the workflow builder. From there you can:

- **Create a new workflow** from scratch
- **Browse the library** for pre-built templates
- **Run an existing workflow** with new inputs
