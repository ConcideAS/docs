---
title: Epona365
---

The Epona365 integration lets you import documents from your Epona365 environment directly into Saga. If your firm uses Epona365 for document management, you can browse and select files without leaving the platform.

## Where you can use it

The Epona365 option appears anywhere you add documents in Saga:

- **Knowledge base** — click **Upload** and select **Upload from Epona365**
- **Chat** — click the attach button and select **Upload from Epona365**
- **Grid review** — click **Add documents** and select **Upload from Epona365**

## Browsing and selecting files

When you open the Epona365 picker, it uses Epona365's own file browser — so the experience is familiar if you already work with Epona365. You can select multiple files at once.

Documents are copied into Saga as a one-way import. Changes in Saga don't sync back to Epona365, and updates in Epona365 don't automatically appear in Saga.

## Setup

Epona365 is configured by your admin from the [admin panel](/guides/admin) under **Settings > Integrations**. Your admin provides the Epona365 instance URL and optionally a SharePoint site collection URL if your Epona365 setup uses one. Once enabled, the integration is available to everyone in your organization.

If you don't see the Epona365 option when uploading documents, ask your admin to enable it.
