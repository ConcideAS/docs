---
title: Connect tools to Saga
---

You can connect external tools and data sources to Saga so the AI can use them while you chat. Once a tool is connected, the AI can call it during a conversation — for example to look something up in a connected system — without you leaving Saga.

An administrator sets up the tool for the whole organization. Some tools also require each person to connect their own account or token before Saga can use the tool in their chats.

## What this is for

Connecting a tool gives Saga's AI a new capability that it uses on your behalf during chats. The tool provider gives you a web address (and sometimes a credential), and Saga handles the rest. Examples include research databases, internal firm systems, or any service that supports the Model Context Protocol.

## Setting up a tool (administrators)

Open the **Admin Panel** and go to the **MCP Servers** section.

1. **Add the tool.** Click **Add Server**, give it a name, and paste the tool's web address (its endpoint URL). The provider of the tool gives you this address.
2. **Set how Saga signs in.** Choose the authentication the tool requires:
   - **None** — the tool needs no credentials.
   - **API Key** or **Bearer Token** — paste the shared key or token the provider gave you. It's stored securely and never shown again.
   - **Basic Auth** — a shared username and password combination, entered in the encoded form the provider specifies.
   - **OAuth 2.1** — enter the OAuth client details the provider gives you, if required. The server is set up for the organization, but the sign-in is personal. Each person must click **Connect** for that tool to connect their own account.
   - **Per-User API Token** — each person enters their own personal token instead of one shared firm credential (see below).
3. **Test and turn it on.** Use **Test Connection** to confirm Saga can reach the tool — a successful test lists the capabilities it found. Turn on **Available in Chat** so people in your organization can use it.

<Note>
Credentials you enter here are stored securely and never displayed again. If you need to change one, enter a new value.
</Note>

## Connect your own account or token

Some tools are set up so that each person connects with their own account or token rather than one shared firm credential. This applies to tools that use **OAuth 2.1** and tools that use **Per-User API Token**.

1. Go to **Settings > Integrations**.
2. Find the tool in the list.
3. Click **Connect** to sign in with OAuth, or paste your personal token if the tool asks for one.
4. Save when Saga asks you to save a token. The tool is now available to you in chat.

Until you connect your own account or token, that tool won't be available in your conversations, even though your administrator has set it up. If chat tells you to reconnect a tool, return to **Settings > Integrations** and connect it again.

<Note>
Want Saga to be the tool that *other* assistants connect to instead? That's the other direction — see [Connect your assistant to Saga](/guides/integrations/mcp-server/connect-assistants).
</Note>
