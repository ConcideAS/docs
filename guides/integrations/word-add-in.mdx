The Saga Word add-in brings Saga's AI into Microsoft Word. Instead of switching between Word and the browser, you can chat with the AI about the document you're working on, run tasks like proofreading and summarization, and apply suggestions directly — all from a sidebar inside Word.

## What you can do

The add-in opens as a task pane on the right side of Word. From there you have access to:

**Chat** — Have a conversation with the AI about the document you're editing. The AI automatically reads the current document as context, so you can ask questions about its content, request analysis, or draft new sections — without pasting anything manually.

**Tasks** — Run built-in tasks on the document or selected text:

- `/proofread` — check grammar, spelling, and style
- `/anonymize` — redact personal identifiers and sensitive information
- `/summarize` — generate a concise summary
- `/compare` — compare sections or versions
- `/auto-fill` — fill in Word templates from source documents (add-in only)

**Answering modes** — Control how the AI responds:

- **Ask** — the AI analyzes and answers without suggesting edits
- **Suggest** — the AI returns structured suggestions you can apply directly to the document, including edits to existing text and new content inserted at specific positions
- **Auto** — the AI decides based on your request whether to analyze or suggest edits

When the AI returns suggestions in **Suggest** mode, you can review each one and apply it to the document with a click — no copy-pasting between tools. Suggestions can replace existing text, append to the end, or insert new paragraphs at a specific location in the document.

## Supported versions

| Platform | Supported versions |
|----------|-------------------|
| **Microsoft 365 (Desktop)** | Word for Microsoft 365 on Windows and Mac |
| **Perpetual licenses** | Word 2024, Word 2021, Word 2019, Word 2016 |
| **Word for the Web** | Supported via browser |
