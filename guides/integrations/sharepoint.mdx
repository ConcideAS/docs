---
title: SharePoint
---

The SharePoint integration lets you import documents from Microsoft SharePoint Online directly into Saga. Instead of downloading files and re-uploading them, you browse your SharePoint sites and folders from inside Saga and pull in what you need.

## Where you can use it

The SharePoint option appears anywhere you add documents in Saga:

- **Knowledge base** — click **Upload** and select **Upload from SharePoint**
- **Chat** — click the attach button and select **Upload from SharePoint**
- **Grid review** — click **Add documents** and select **Upload from SharePoint**

## Browsing and selecting files

When you open the SharePoint picker, you'll sign in with your Microsoft account. From there you can browse the SharePoint sites you have access to, navigate through folder structures, and search for specific files. You can select multiple files and folders at once — selecting a folder includes everything inside it.

Documents are copied into Saga as a one-way import. Changes you make to the document in Saga don't sync back to SharePoint, and updates in SharePoint don't automatically appear in Saga. If you need an updated version, import it again.

In the SharePoint picker, choose **Pin to top** on a site to keep it at the top of the list. Pinned sites show under **Pinned**, and the other sites show under **All sites**, both in A to Z order. Search results use the same split. Choose **Unpin** to remove a pin. You can pin up to 50 sites.

## Setup

SharePoint is configured by your admin from the [admin panel](/guides/administration/admin-panel) under **Settings > Integrations**. Your admin provides the SharePoint tenant URL (e.g., `https://your-firm.sharepoint.com`) and enables the integration. Once it's on, everyone in your organization can use it.

SharePoint import needs admin consent for the `Sites.Read.All` Graph scope. For the full permission list, see [Microsoft permissions](/guides/integrations/microsoft-permissions).

If you don't see the SharePoint option when uploading documents, ask your admin to enable it.
