---
title: Admin panel
description: Manage your organization's settings, integrations, users, and shared libraries.
---

The admin panel is available to organization administrators. Access it by clicking **Admin panel** in the sidebar.

## Preferences

### Workspace settings

Configure general workspace settings including naming, theme, and default behaviors.

### AI policy

Set organization-wide AI usage policies that apply to all users.

## Organization

### Users

Manage team members:

- Invite new users
- Assign roles and permissions
- Remove users from the organization

### Integrations

Connect Saga with external tools and services your team uses.

### MCP servers

Configure Model Context Protocol servers for advanced integrations.

### Organizational sources

Create shared knowledge bases at the organization level. Unlike matter-specific knowledge bases, organizational sources are available across all matters and chats for every user.

### Usage

Monitor your organization's usage of Saga features, including AI message counts and storage.

## Libraries

### Prompt library

Create and manage shared prompts available to all users:

1. Go to **Libraries** > **Prompts**.
2. Click **New prompt**.
3. Write the prompt template and give it a descriptive name.
4. Save — it appears in every user's prompt library.

### Grid review templates

Create reusable question sets for grid reviews:

1. Go to **Libraries** > **Grid review templates**.
2. Click **New template**.
3. Define the questions (columns) for the template.
4. Save — users can select it when creating new grid reviews.

### Custom assistants

Build assistants with specific instructions and capabilities:

1. Go to **Libraries** > **Custom assistants**.
2. Click **New assistant**.
3. Configure the assistant's name, instructions, and behavior.
4. Save — it appears in the assistant selector for all users.

### Workflows

Manage shared workflows available to the organization:

1. Go to **Libraries** > **Workflows**.
2. Create or import workflows.
3. Published workflows appear in every user's workflow library.
