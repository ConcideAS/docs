title: Search modes and filters

---

Saga offers several ways to refine your legal research results. The available options vary by database.

## Search modes

| Mode | How it works |
|------|-------------|
| **Prompt** | Natural language search — describe what you're looking for in plain language |
| **Keyword** | Traditional keyword search — match specific terms and phrases |
| **Hybrid** | Combines natural language understanding with keyword matching |

Not every database supports all three modes. The available modes appear in the search input when you select a database.

## Improve prompt

Click **Improve prompt** to let the AI refine your search query before running it. This can help you get more targeted results, especially when using natural language search.

## Filters

Filters appear in the sidebar and vary by database:

| Filter | Available for |
|--------|--------------|
| **Fields of law** | Moonlit |
| **Document types** | Moonlit, Lovdata |
| **Jurisdictions** | Moonlit, Rettsdata, Rechtspraak.nl |
| **Institutions** | Rettsdata, Rechtspraak.nl |
| **Portals** | Moonlit |
| **Tax types** | Kennisbank |
| **Date range** | Most databases |

Select one or more filter values to narrow your results. Clear filters to return to the full result set.

## Sorting

Sort results by:

- **Relevance** — Most relevant results first (default)
- **Newest** — Most recent documents first
- **Oldest** — Oldest documents first

## Browse mode

Some databases support browsing without entering a search query. This lets you explore recent or featured content directly.
