---
title: Grid review
---

Grid review lets you analyze multiple documents systematically. Each document becomes a row, each question becomes a column, and the AI fills in the answers — giving you a structured table you can review, edit, and export.

<Tip>
Set up a grid review to extract key dates, termination clauses, and change-of-control provisions from a set of contracts — all in one structured view.
</Tip>

## Create a grid review

<Steps>
  <Step title="Open a project">
    Go to **Projects** and open the project containing your documents.
  </Step>
  <Step title="Start a new grid">
    Click the **Grid review** tab, then click **New grid review**. Choose to create a blank grid or start from a [template](/guides/grid-review/templates).
  </Step>
  <Step title="Name your grid">
    Give the grid a descriptive name. Optionally add a custom instruction that applies to all questions in the grid.
  </Step>
  <Step title="Add questions">
    Define the questions you want answered for each document. Each question becomes a column. Choose a [question type](/guides/grid-review/question-types) for each column.
  </Step>
  <Step title="Add documents">
    Select documents from the project's knowledge base to include. Each document becomes a row.
  </Step>
  <Step title="Run the review">
    Click **Run** and the AI analyzes each document against your questions, filling in the grid cell by cell.
  </Step>
</Steps>

## Custom instructions

When creating or editing a grid, you can add a custom instruction that provides additional context to the AI. For example: "Focus on financial terms and obligations" or "Answer in the context of Norwegian law."

Each question can individually opt in or out of using the grid-level instruction.
