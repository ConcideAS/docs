title: NetDocuments
---

NetDocuments-integrationen låter dig importera dokument från NetDocuments direkt till Saga. Om din byrå använder NetDocuments för dokumenthantering kan du bläddra och välja filer utan att lämna plattformen.

## Var du kan använda det

NetDocuments-alternativet visas överallt där du lägger till dokument i Saga:

- **Kunskapsbas** — klicka på **Ladda upp** och välj **Ladda upp från NetDocuments**
- **Chatt** — klicka på bifoga-knappen och välj **Ladda upp från NetDocuments**
- **Tabellgranskning** — klicka på **Lägg till dokument** och välj **Ladda upp från NetDocuments**

## Bläddra och välja filer

När du öppnar NetDocuments-väljaren kan du bläddra bland dina cabinets, arbetsytor och mappar. Du kan välja flera filer samtidigt.

Dokument kopieras till Saga som en envägsimport. Ändringar i Saga synkroniseras inte tillbaka till NetDocuments, och uppdateringar i NetDocuments visas inte automatiskt i Saga.

## Konfiguration

NetDocuments konfigureras av din admin från [adminpanelen](/sv/guides/admin) under **Inställningar > Integrationer**. Din admin aktiverar integrationen, anger byråns ndConnect Vendor Access Key (börjar med `ak_`) och väljer den region som motsvarar ert NetDocuments-datacenter. Vendor Access Keys kan begäras från NetDocuments via apisupport@netdocuments.com. När den är påslagen är integrationen tillgänglig för alla i din organisation.

Om du inte ser NetDocuments-alternativet när du laddar upp dokument, be din admin att aktivera det.
