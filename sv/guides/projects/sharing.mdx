---
title: Delning och behörigheter
---

Projekt kan delas med andra personer i din organisation. När du delar ett projekt får medarbetare tillgång till dess kunskapsbas, chattar och tabellgranskningar — inom ramarna för den behörighetsnivå du tilldelar.

## Behörighetsnivåer

| Behörighet | Vad det innebär |
|------------|----------------|
| **Ägare** | Full kontroll över projektet. Personen som skapade det är alltid ägare. |
| **Medägare** | Samma åtkomst som ägaren — kan redigera, dela och ta bort projektet. |
| **Kan redigera** | Kan ladda upp dokument, skapa chattar och genomföra tabellgranskningar, men kan inte hantera delning eller ta bort projektet. |
| **Skrivskyddad** | Kan se allt i projektet men kan inte göra ändringar. |

Använd **medägare** för kollegor som behöver hantera projektet tillsammans med dig. Använd **kan redigera** för teammedlemmar som gör det dagliga arbetet. Använd **skrivskyddad** för personer som behöver insyn utan möjlighet att ändra något.

## Dela ett projekt

Öppna projektet, klicka på **Dela** i sidhuvudet och sök efter en kollega med namn eller e-post. Välj deras behörighetsnivå och lägg till dem. De får åtkomst omedelbart.

Om din organisation sträcker sig över flera e-postdomäner — till exempel efter en sammanslagning eller mellan regionala kontor — kan du dela med kollegor i alla domäner som din admin har kopplat samman. De dyker upp i samma sökning och beter sig som vilken annan medlem som helst.

Du kan ändra någons behörighetsnivå eller ta bort deras åtkomst när som helst från samma dialog. För att ta bort alla medarbetare på en gång, klicka på **Sluta dela**.

## Dela chattar

Chattar inom ett delat projekt är privata som standard — bara du kan se dem. För att göra en chatt synlig för alla projektmedlemmar, klicka på **Dela** i chattens sidhuvud. Ett systemmeddelande visas i konversationen när delning aktiveras.

Du kan filtrera chattlistan efter **Alla**, **Privata** eller **Delade** för att hitta det du behöver.

## Lämna ett projekt

Om du inte är ägare kan du lämna ett projekt från menyn **...** i projektets sidhuvud. Att lämna tar bort din åtkomst — ägaren kan lägga till dig igen när som helst.
