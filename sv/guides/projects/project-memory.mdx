# Översikt

Projektminne håller koll på användbar kontext från ditt arbete i ett projekt, som viktiga fakta, beslut och preferenser från dina chattar. När du återvänder till ett projekt och startar en ny chatt vet Saga redan var du slutade, så du slipper förklara bakgrunden igen.

Saga sparar minnen automatiskt när du chattar i ett projekt. Du kan också lägga till, redigera och ta bort minnen själv när som helst.

## Hur minnen skapas

När du chattar i ett projekt plockar Saga upp information värd att komma ihåg och sparar den som ett minne. När detta händer visas en **Minne uppdaterat**-indikator ovanför svaret. Hovra över den för att se vad som sparades, och välj **Hantera** för att öppna den fullständiga listan.

Du kan också lägga till minnen manuellt. Detta är användbart för kontext som Saga inte kan härleda på egen hand, som en klients föredragna avtalsvillkor eller en intern deadline.

## Visa projektminnen

1. Öppna projektet.
2. Välj **⋯**-menyn högst upp på projektsidan, välj sedan **Projektminnen**.

Dialogen listar allt projektet minns. Använd sökfältet för att hitta ett specifikt minne, eller filtrera listan efter tagg.

## Lägga till ett minne

1. Öppna **Projektminnen** från projektmenyn.
2. Välj **Lägg till minne**.
3. Skriv in minnesinnehållet.
4. Välj eventuellt **Lägg till tagg** för att tagga minnet. Taggar hjälper dig att filtrera minnen senare.
5. Välj **Spara**.

## Redigera eller ta bort ett minne

1. Öppna **Projektminnen** och hitta minnet. Använd sökning eller taggfilter om listan är lång.
2. Välj pennikonen för att redigera dess innehåll eller taggar, eller papperskorgsikonen för att ta bort det.

När du tar bort ett minne försvinner det från projektets kontext. Saga kommer inte längre att använda det i sina svar.

## Vem kan hantera minnen

Alla med åtkomst till ett projekt kan visa dess minnen. Att lägga till, redigera och ta bort minnen kräver redigeringsåtkomst: projektägare, medägare och medlemmar med redigeringsbehörighet.

## Tips

- Granska minnen när du startar ett långvarigt ärende. En snabb upprensning håller Sagas kontext korrekt allt eftersom arbetet utvecklas.
- Ta bort minnen som är föråldrade eller felaktiga. Gammal kontext leder till gamla svar.
- Använd taggar för att gruppera minnen efter ämne, till exempel efter motpart, avtal eller arbetsström.
