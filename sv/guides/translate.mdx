---
title: Översätt
---

Saga inkluderar inbyggd översättning driven av DeepL. Du kan översätta text eller hela dokument mellan 30+ språk — inklusive regionala varianter som brittisk och amerikansk engelska eller brasiliansk och europeisk portugisiska — utan att lämna plattformen. Klicka på **Översättning** i sidofältet för att öppna det.

## Text

Klistra in eller skriv text i källområdet, välj ditt målspråk, och översättningen visas till höger. Källspråket identifieras automatiskt, eller så kan du ställa in det manuellt. Klicka på **Kopiera** för att ta resultatet.

## Dokument

Dra och släpp filer i källområdet, eller klicka för att bläddra på din dator. Du kan även hämta dokument från ett projekts kunskapsbas eller Epona365. De översatta filerna visas som nedladdningsbara markeringar i utmatningsområdet — klicka för att ladda ner individuellt, eller använd **Ladda ner alla** när du har översatt ett parti.

Medan ett dokument översätts visar raden hur lång tid som återstår, enligt uppskattningen från DeepL. Om översättningen tar längre tid än uppskattningen visar raden **Det tar längre tid än väntat. Översättningen pågår fortfarande.**

Om en översättning misslyckas visar raden **Kunde inte översätta**. Klicka på **Försök igen** för att översätta samma fil igen med samma språk. Du behöver inte ladda upp filen på nytt.

För att spara en översatt fil i ett projekt klickar du på ikonen **Lägg till i projekt** på raden och väljer ett projekt eller en mapp. För att lägga till alla färdiga översättningar på en gång klickar du på **Lägg till alla i projekt**. Listan visar bara projekt som du kan redigera, och du kan klicka på **Skapa nytt projekt** för att lägga till ett nytt. Du kan till exempel översätta en uppsättning bilagor och lägga dem direkt i ärendets kunskapsbas.

Stödda format: **DOCX**, **PPTX**, **XLSX**, **PDF**, **HTML**, **TXT**, **XLF/XLIFF** och **SRT**. Formatering bevaras vid översättning.

| Format | Storleksgräns |
|--------|--------------|
| DOCX, PPTX, XLSX, PDF | 30 MB |
| XLF, XLIFF | 10 MB |
| HTML | 5 MB |
| TXT, SRT | 1 MB |

<Note>
Översatta dokument är tillgängliga för nedladdning en gång. Efter att du laddat ner en fil tas den bort från listan och kan inte laddas ner igen — så spara den där du behöver den.
</Note>
