Die Rasterprüfung ermöglicht es Ihnen, eine Reihe von Dokumenten anhand derselben Fragen in einem strukturierten Durchgang zu analysieren. Definieren Sie, was Sie wissen möchten — Kündigungsklauseln, Wirksamkeitsdaten, anwendbares Recht, Haftungsgrenzen — und die KI arbeitet jedes Dokument durch und füllt eine Tabelle aus, in der jede Zeile ein Dokument und jede Spalte eine Frage ist.

Sie ist für die Art von Arbeit konzipiert, bei der Sie normalerweise zwanzig Verträge nebeneinander öffnen und von Hand eine Tabelle erstellen würden. Die Rasterprüfung erledigt das in Minuten, mit Quellenverweisen, die jede Antwort auf die Quellpassage zurückführen.

## Wo Rasterprüfungen gespeichert werden

Rasterprüfungen können innerhalb eines [Projekts](/de/guides/projects) oder eigenständig existieren. Innerhalb eines Projekts finden Sie sie unter dem Tab **Rasterprüfung** neben dem Chat. Das Raster hat automatisch Zugriff auf die [Wissensdatenbank](/de/guides/projects/knowledge-base) des Projekts, sodass Sie Dokumente direkt von dort abrufen können.

Sie können auch eigenständige Raster über die Seite **Rasterprüfungen** in der Seitenleiste erstellen. Eigenständige Raster haben einen eigenen Dokumentensatz. Wenn Sie später entscheiden, dass ein Raster in ein Projekt gehört, können Sie es verschieben.

## Ein Raster erstellen

Klicken Sie auf **Neue Rasterprüfung**, um von Grund auf zu beginnen, oder öffnen Sie die **Raster-Bibliothek**, um mit einer [Vorlage](/de/guides/grid-review/templates) zu starten. Geben Sie dem Raster einen Namen, der die Aufgabe identifiziert — „Mietvertragsanalyse" oder „Arbeitsvertragsprüfung" funktionieren gut. Sie können das Raster auch mit einem oder mehreren [Praxisbereichen](/de/guides/quickstart#praxisbereiche) taggen, damit es später unter dem passenden Filter erscheint.

Von dort aus fügen Sie Fragen und Dokumente hinzu. Fragen werden zu Spalten; Dokumente werden zu Zeilen. Die KI beginnt mit der Generierung von Antworten, sobald beides vorhanden ist.

## Antwortmodi

Jede Frage hat einen Antwortmodus, der der KI mitteilt, welche Art von Antwort Sie erwarten. Die Wahl des richtigen Modus sorgt für konsistente Ergebnisse und macht das Raster leichter überschaubar.

| Modus | Was die KI zurückgibt | Wann verwenden |
|-------|----------------------|----------------|
| **Extrahieren** | Wörtlicher Text aus dem Dokument | Bestimmte Klauseln, Definitionen oder Passagen herausziehen |
| **Kurzanalyse** | Eine kurze Zusammenfassung oder Analyse | Schnelle Bewertungen, knappe Beobachtungen |
| **Ausführliche Analyse** | Eine detaillierte, mehrteilige Analyse | Vertiefte Prüfungen, mehrteilige Fragen |
| **Wahr / Falsch** | Wahr oder Falsch | Binäre Prüfungen — „Enthält der Vertrag eine Wettbewerbsverbotsklausel?" |
| **Datum** | Ein Datum | Wirksamkeitsdaten, Fristen, Ablaufdaten |
| **Zahl** | Ein numerischer Wert | Finanzkennzahlen, Mengen, Grenzwerte |
| **Währung** | Ein Geldbetrag | Vertragswerte, Gebühren, Vertragsstrafen |

Wenn die KI nicht finden kann, wonach Sie fragen, teilt sie es Ihnen mit — „Angefragtes Datum nicht gefunden" oder „Wahr oder Falsch kann nicht bestimmt werden" — anstatt zu raten.

Sie können auch auf **Prompt verbessern** klicken, wenn Sie eine Frage formulieren, damit die KI Ihre Formulierung für präzisere Ergebnisse verfeinert.

## Benutzerdefinierte Anweisungen

Wenn es einen Kontext gibt, den die KI bei allen Fragen berücksichtigen soll — einen Rechtsgebietsschwerpunkt, einen bestimmten Rechtsrahmen, eine Formatierungspräferenz — können Sie ihn als benutzerdefinierte Anweisung beim Erstellen oder Bearbeiten des Rasters hinzufügen. Etwas wie „Antworten Sie im Kontext des deutschen Arbeitsrechts" oder „Konzentrieren Sie sich auf finanzielle Verpflichtungen und Vertragsstrafen."

Jede Frage kann die rasterweite Anweisung ein- oder ausschliessen, sodass Sie kontrollieren können, welche Fragen vom zusätzlichen Kontext profitieren und welche eigenständig bleiben sollen.

## Dokumente hinzufügen

Sie können Dokumente aus verschiedenen Quellen hinzufügen: aus jeder für Sie zugänglichen [Wissensdatenbank](/de/guides/projects/knowledge-base) (nicht nur der des aktuellen Projekts), per Datei-Upload oder über Integrationen wie SharePoint und Epona365, sofern Ihre Organisation diese konfiguriert hat. Wählen Sie so viele aus, wie Sie benötigen — die KI generiert Antworten für jedes Dokument zu jeder Frage.

Dokumente können jederzeit hinzugefügt oder entfernt werden. Wenn Sie neue Dokumente zu einem bestehenden Raster hinzufügen, füllt die KI die Antworten automatisch aus. Das Raster ist bei der Erstellung nicht festgelegt.
