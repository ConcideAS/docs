---
title: Wissensdatenbank
---

Die Wissensdatenbank ist die Dokumentenbibliothek innerhalb eines Projekts. Jede hochgeladene Datei wird von Saga verarbeitet — der Text wird extrahiert, in Passagen unterteilt und so gespeichert, dass die KI die relevantesten Abschnitte finden kann, wenn Sie eine Frage stellen. Dadurch basieren die Antworten von Saga auf Ihren tatsächlichen Dokumenten und nicht auf allgemeinem Wissen.

## Dokumente hinzufügen

Ziehen Sie Dateien oder Ordner per Drag-and-Drop direkt in das Wissensdatenbank-Panel oder klicken Sie auf **Hochladen**, um Dateien auf Ihrem Computer zu durchsuchen. Wenn Ihre Organisation SharePoint oder Epona365 konfiguriert hat, können Sie auch Dateien aus diesen Diensten importieren.

Saga unterstützt eine Vielzahl von Dateiformaten:

| Kategorie      | Formate                             |
| -------------- | ----------------------------------- |
| Dokumente      | PDF, DOC, DOCX, TXT, HTML, CSV, ODT |
| Tabellen       | XLS, XLSX, ODS                      |
| Präsentationen | PPTX                                |
| E-Mail         | EML, MSG                            |
| Bilder         | PNG, JPG, JPEG, GIF, WEBP, TIFF     |

Die maximale Dateigrösse beträgt 1 GB. Ein Projekt kann bis zu 1.000 Dokumente enthalten.

Nach dem Hochladen durchläuft jede Datei eine Verarbeitung, bevor sie der KI zur Verfügung steht. Sie können währenddessen weiterarbeiten — Dokumente werden automatisch verfügbar, sobald sie verarbeitet sind. Wenn die Verarbeitung einer Datei fehlschlägt, können Sie sie über das Aktionsmenü erneut versuchen.

## Aktive und inaktive Dokumente

Jedes Dokument hat einen Aktiv-/Inaktiv-Schalter. Nur aktive Dokumente werden von der KI als Kontext verwendet. Inaktive Dokumente bleiben in der Wissensdatenbank, werden aber vom Chat und der Rasterprüfung ausgeschlossen.

Dies ist nützlich, wenn Sie den Fokus der KI auf eine bestimmte Teilmenge von Dateien einschränken möchten — beispielsweise in einer Phase eines Mandats, in der nur bestimmte Verträge relevant sind.

## Ordner und Tags

Sie können Dokumente mit Ordnern und farbcodierten Tags organisieren.

**Ordner** ermöglichen es Ihnen, Ihre bestehende Dateistruktur nachzubilden. Erstellen Sie verschachtelte Ordner, verschieben Sie Dokumente per Drag-and-Drop zwischen ihnen und laden Sie einen ganzen Ordner als ZIP herunter, wenn Sie Dateien ausserhalb von Saga teilen möchten. Der Auf-/Zugeklappt-Status Ihrer Ordner wird automatisch gespeichert und bleibt beim Aktualisieren der Seite erhalten, sodass Sie immer zu der Ansicht zurückkehren, die Sie verlassen haben.

**Tags** funktionieren ordnerübergreifend. Weisen Sie einem Dokument ein Tag zu, geben Sie ihm eine Farbe und verwenden Sie den Tag-Filter, um nur Dokumente mit diesem Label anzuzeigen. Tags eignen sich zur Kennzeichnung von Dokumenttypen, Prüfstatus oder allem, was Ihre Ordnerstruktur übergreifend betrifft.

## Dateivorschau

Sie können bestimmte Dateitypen direkt im Seitenpanel anzeigen, ohne sie herunterladen zu müssen. Klicken Sie auf ein Dokument in der Wissensdatenbank oder auf ein Zitat im Chat, um es zu öffnen.

| Dateityp       | Vorschauverhalten                                                                 |
| -------------- | --------------------------------------------------------------------------------- |
| Bilder         | PNG-, JPG-, JPEG-, GIF-, WEBP- und TIFF-Dateien öffnen sich in einem Bildbetrachter mit Zoom-Steuerung. Klicken Sie auf die Zurücksetzen-Schaltfläche, um zur Originalgrösse zurückzukehren. |
| CSV            | CSV-Dateien werden in einer tabellenartigen Ansicht mit beschrifteten Spalten und nummerierten Zeilen angezeigt. Sie können hinein- und herauszoomen, um die Ansicht anzupassen. |
| Klartext       | TXT-Dateien werden mit ihrer ursprünglichen Formatierung dargestellt.              |
| PDF und DOCX   | Diese werden weiterhin im integrierten Dokumentenbetrachter mit Seitennavigation und Zitat-Hervorhebung geöffnet. |

Bei grossen CSV- und Klartextdateien wird nur ein Teil des Inhalts angezeigt. Ein Banner am unteren Rand informiert Sie, wenn die Vorschau gekürzt wurde — laden Sie die Datei herunter, um den vollständigen Inhalt zu sehen.

## Dokumentaktionen

Jedes Dokument verfügt über ein Aktionsmenü, in dem Sie es umbenennen, in einen anderen Ordner verschieben, Tags verwalten, herunterladen, die Verarbeitung erneut starten oder löschen können. Sie können auch mehrere Dokumente gleichzeitig für den Massen-Download oder die Massenlöschung auswählen.

Beim Auswählen von Dokumenten zeigen Ordner-Kontrollkästchen einen Teilauswahl-Indikator, wenn nur einige Dateien darin ausgewählt sind, sodass Sie genau sehen können, was enthalten ist. Das Umschalten des Aktivstatus eines einzelnen Dokuments zeigt den Ladeindikator nur bei diesem Element an, sodass Sie mit dem Rest der Liste weiterarbeiten können.
