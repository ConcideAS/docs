---
title: Wissensdatenbank
---

Die Wissensdatenbank ist die Dokumentenbibliothek innerhalb eines Projekts. Jede hochgeladene Datei wird von Saga verarbeitet — der Text wird extrahiert, in Passagen unterteilt und indiziert, sodass die KI bei Bedarf das passende Material finden kann. Wenn Sie in einem Projekt-Chat eine Frage stellen, durchsucht die KI die gesamte Wissensdatenbank und holt die für Ihre Frage relevantesten Passagen heraus — mit Quellenverweisen, die zu jeder Quelle zurückführen. Sie wählen nicht aus, welche Dokumente die KI ansieht — sie entscheidet das pro Frage, basierend auf dem, was Sie tatsächlich fragen.

## Dokumente hinzufügen

Ziehen Sie Dateien oder Ordner per Drag-and-Drop direkt in das Wissensdatenbank-Panel oder klicken Sie auf **Hochladen**, um Dateien auf Ihrem Computer zu durchsuchen. Wenn Ihre Organisation SharePoint oder Epona365 konfiguriert hat, können Sie auch Dateien aus diesen Diensten importieren.

Saga unterstützt eine Vielzahl von Dateiformaten:

| Kategorie      | Formate                             |
| -------------- | ----------------------------------- |
| Dokumente      | PDF, DOC, DOCX, TXT, HTML, CSV, ODT |
| Tabellen       | XLS, XLSX, ODS                      |
| Präsentationen | PPTX                                |
| E-Mail         | EML, MSG                            |
| Bilder         | PNG, JPG, JPEG, GIF, WEBP, TIFF     |

Die maximale Dateigrösse beträgt 1 GB. Ein Projekt kann bis zu 1.000 Dokumente enthalten. Wenn ein Projekt nahe an seinem Dokumentlimit ist, zeigt die Kopfzeile der Wissensdatenbank einen Nutzungs-Badge mit der Anzahl der verwendeten Dokumente und dem Limit, zum Beispiel `820/1000`. Der Badge erscheint, wenn das Projekt etwa 80 % seines Dokumentlimits erreicht. Unterhalb dieses Schwellenwerts wird er nicht angezeigt.

Nach dem Hochladen durchläuft jede Datei eine Verarbeitung, bevor sie der KI zur Verfügung steht. Sie können währenddessen weiterarbeiten — Dokumente werden automatisch verfügbar, sobald sie verarbeitet sind. Wenn die Verarbeitung einer Datei fehlschlägt, können Sie sie über das Aktionsmenü erneut versuchen. Wenn mehr als ein Upload fehlschlägt, erscheint oben in der Wissensdatenbank eine Wiederherstellungsleiste, damit Sie alle fehlgeschlagenen Uploads in einem Schritt **alle erneut versuchen** oder **alle fehlgeschlagenen löschen** können.

## Ordner und Tags

Sie können Dokumente mit Ordnern und farbcodierten Tags organisieren.

**Ordner** ermöglichen es Ihnen, Ihre bestehende Dateistruktur nachzubilden. Erstellen Sie verschachtelte Ordner, verschieben Sie Dokumente per Drag-and-Drop zwischen ihnen und laden Sie einen ganzen Ordner als ZIP herunter, wenn Sie Dateien ausserhalb von Saga teilen möchten. Der Auf-/Zugeklappt-Status Ihrer Ordner wird automatisch gespeichert und bleibt beim Aktualisieren der Seite erhalten, sodass Sie immer zu der Ansicht zurückkehren, die Sie verlassen haben.

**Tags** funktionieren ordnerübergreifend. Weisen Sie einem Dokument ein Tag zu, geben Sie ihm eine Farbe und verwenden Sie den Tag-Filter, um nur Dokumente mit diesem Label anzuzeigen. Tags eignen sich zur Kennzeichnung von Dokumenttypen, Prüfstatus oder allem, was Ihre Ordnerstruktur übergreifend betrifft.

## Dokumentaktionen

Jedes Dokument verfügt über ein Aktionsmenü, in dem Sie es umbenennen, in einen anderen Ordner verschieben, Tags verwalten, herunterladen, die Verarbeitung erneut starten oder löschen können.

Um mehrere Dokumente gleichzeitig zu bearbeiten, verwenden Sie die Kontrollkästchen neben jedem Dokument oder Ordner. Mit einer aktiven Auswahl können Sie alle ausgewählten Dokumente in einem Schritt **herunterladen**, **löschen**, **verschieben** oder **taggen**. Ordner-Kontrollkästchen zeigen einen Teilauswahl-Indikator an, wenn nur einige Dateien darin ausgewählt sind, damit Sie genau sehen, was enthalten ist.
