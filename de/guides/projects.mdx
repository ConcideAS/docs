Ein Projekt ist Ihr Arbeitsbereich für einen Fall, eine Transaktion oder ein anderes Arbeitsvorhaben. Es bündelt alles an einem Ort — die Dokumente, mit denen Sie arbeiten, die KI-Unterhaltungen, die Sie geführt haben, und die strukturierten Prüfungen, die Sie durchgeführt haben. Wenn Sie der KI innerhalb eines Projekts eine Frage stellen, greift sie automatisch auf die Dokumente dieses Projekts zurück.

## Projekt erstellen

Klicken Sie auf **Projekte** in der Seitenleiste und dann auf **Neues Projekt**. Geben Sie ihm einen Namen, der das Mandat identifiziert — ein Fallname, eine Mandatsreferenz oder ein Geschäftsname eignen sich gut.

Sie können ausserdem einige optionale Einstellungen vorab konfigurieren:

- **Beschreibung** — eine kurze Notiz auf der Projektkarte. Klicken Sie auf **Mit KI generieren**, wenn Saga sie aus dem Projektnamen entwerfen soll.
- **Standard-Assistent** — das KI-Modell oder der benutzerdefinierte Assistent, der standardmässig für neue Chats in diesem Projekt geöffnet wird
- **Tags** — Labels auf der Projektkarte und in den Listenfiltern
- **Fälligkeitsdatum** — ein optionales Datum auf der Karte, damit anstehende Arbeit sichtbar bleibt
- **Benutzerdefinierte Anweisungen** — dauerhafter Kontext, der für jede KI-Interaktion im Projekt gilt, z. B. „Dieses Mandat betrifft deutsches Arbeitsrecht" oder „Antworten Sie immer auf Deutsch"

Sie können diese Einstellungen jederzeit über das Einstellungsmenü des Projekts ändern.

Auf der Seite **Projekte** finden Sie ein Projekt mit **Sortieren** und **Filtern** nach Tag, Fälligkeitsdatum, Status oder Personen. Archivierte Projekte bleiben aus der Standardliste, bis Sie sie im Filter einbeziehen.

## Was ein Projekt enthält

Jedes Projekt hat zwei Tabs: **Chat** und **Rasterprüfung**.

Der **Chat**-Tab ist der Bereich für KI-Unterhaltungen im Kontext des Projekts. Sie können jederzeit das Wissensdatenbank-Panel öffnen, indem Sie auf **Wissensdatenbank anzeigen** klicken, um Dateien zu verwalten und gleichzeitig Fragen zu stellen.

Der **Rasterprüfung**-Tab dient der strukturierten Dokumentenprüfung. Definieren Sie einen Fragenkatalog, wählen Sie die Dokumente aus, und die KI analysiert jedes einzelne anhand Ihrer Fragen in einem Tabellenformat.

Beide Tabs greifen auf dieselbe Wissensdatenbank zu — jedes hochgeladene Dokument steht sowohl im Chat als auch in der Rasterprüfung zur Verfügung.

## Projekt anpassen

Beschreibung, Standard-Assistent, Tags, Fälligkeitsdatum und benutzerdefinierte Anweisungen bestimmen, wie sich die KI in einem Projekt verhält. Sie können sie beim Erstellen des Projekts festlegen oder später hinzufügen (siehe Projekt bearbeiten).

Benutzerdefinierte Anweisungen machen den grössten Unterschied. Sie sind dauerhafter Kontext, der für jede KI-Interaktion im Projekt gilt, sodass Sie denselben Hintergrund nicht in jedem neuen Chat wiederholen müssen. Gute Anweisungen nennen Fakten zum Mandat und Vorgaben für die Antworten:

- Rechtsordnung und Rechtsgebiet, z. B. „Dieses Mandat betrifft niederländisches Arbeitsrecht"
- Sprache und Stil, z. B. „Antworten Sie immer auf Norwegisch" oder „Halten Sie Antworten kurz"
- Hintergrund, den die KI kennen sollte, etwa Parteien, wichtige Daten oder definierte Begriffe

Anweisungen gelten nur innerhalb des Projekts. Halten Sie sie sachlich und konkret: Je präziser sie das Mandat beschreiben, desto relevanter wird jede Antwort.

## Projekt bearbeiten

Öffnen Sie das Projekt, klicken Sie auf das **...**-Menü in der Kopfzeile und wählen Sie **Projekt bearbeiten**. Sie können Name, Beschreibung, Standard-Assistenten, Tags, Fälligkeitsdatum und benutzerdefinierte Anweisungen jederzeit aktualisieren.

## Projekt löschen

Öffnen Sie das **...**-Menü und wählen Sie **Projekt löschen**. Das Löschen ist endgültig — es entfernt alle Dokumente, Chats und Rasterprüfungen im Projekt. Wenn das Projekt geteilt ist, verlieren Mitarbeiter sofort den Zugang.
