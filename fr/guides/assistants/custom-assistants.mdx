---
title: Assistants personnalisés
---

Un assistant personnalisé est une IA configurée pour une tâche spécifique. Il est construit par-dessus un modèle — GPT, Claude ou tout autre — mais il est doté d'instructions structurées qui façonnent son comportement. Au lieu de partir d'une page blanche, l'assistant sait déjà ce qu'il examine, ce qu'il doit faire et comment présenter ses résultats.

<Note>
  Les assistants personnalisés sont gérés par les administrateurs depuis le panneau d'administration. Si vous
  avez besoin d'un assistant pour un workflow qui n'en dispose pas encore, ou si vous souhaitez
  ajuster le comportement d'un assistant existant, adressez-vous à votre administrateur.
</Note>

## Ce qui les différencie

Lorsque vous utilisez un modèle directement, vous êtes responsable de tout le contexte : expliquer la tâche, spécifier le format, définir le public. Un assistant personnalisé gère tout cela en amont. Ses instructions sont structurées autour de cinq axes :

- **Contexte** — les informations de base dont l'IA a besoin, comme le type de documents sur lesquels elle travaille ou la juridiction sur laquelle elle doit se concentrer
- **Objectif** — ce que l'assistant doit accomplir lorsque vous lui posez une question
- **Style** — comment il doit communiquer : formel, concis, détaillé ou selon les préférences de votre cabinet
- **Public** — pour qui il écrit, qu'il s'agisse d'un associé, d'un client ou d'un conseil adverse
- **Format de réponse** — comment structurer le résultat : puces, format mémo, tableau ou autre

Ces champs sont ce qui distingue un assistant bien configuré d'un prompt générique. Ils assurent la cohérence du résultat entre les utilisateurs et les conversations — ainsi l'assistant de revue de contrats du cabinet produit le même style d'analyse, quel que soit l'utilisateur.

Les administrateurs peuvent aussi joindre des documents d'instructions à un assistant personnalisé. Saga intègre le texte extrait dans les instructions de l'assistant, ce qui convient aux playbooks, au style de la firme ou à une liste de clauses qui doivent rester avec l'assistant plutôt que d'être rattachées à chaque conversation.

## Consulter les détails d'un assistant

Avant d'utiliser un assistant personnalisé, vous pouvez voir exactement à quoi il est destiné. Survolez-le dans le sélecteur d'assistant pour voir sa description et le modèle sur lequel il est construit. Cliquez sur **Voir les détails** pour la configuration complète, y compris tous les champs d'instructions.

C'est utile lorsque vous hésitez à savoir si un assistant convient à votre tâche, ou lorsque vous souhaitez comprendre pourquoi il vous donne un type de réponse particulier.
