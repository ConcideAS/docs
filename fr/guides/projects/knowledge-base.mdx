---
title: Base de connaissances
---

La base de connaissances est la bibliothèque de documents d'un projet. Chaque fichier que vous importez est traité par Saga — le texte est extrait, découpé en passages et stocké de manière à ce que l'IA puisse trouver les parties les plus pertinentes lorsque vous posez une question. C'est ce qui fait que les réponses de Saga s'appuient sur vos documents réels plutôt que sur des connaissances générales.

## Ajouter des documents

Glissez-déposez des fichiers ou des dossiers directement dans le panneau de la base de connaissances, ou cliquez sur **Importer** pour parcourir votre ordinateur. Si votre organisation a configuré SharePoint ou Epona365, vous pouvez également importer des fichiers depuis ces services.

Saga prend en charge un large éventail de formats de fichiers :

| Catégorie      | Formats                             |
| -------------- | ----------------------------------- |
| Documents      | PDF, DOC, DOCX, TXT, HTML, CSV, ODT |
| Tableurs       | XLS, XLSX, ODS                      |
| Présentations  | PPTX                                |
| E-mails        | EML, MSG                            |
| Images         | PNG, JPG, JPEG, GIF, WEBP, TIFF     |

La taille maximale par fichier est de 1 Go. Un projet peut contenir jusqu'à 1 000 documents.

Après l'import, chaque fichier passe par un traitement avant d'être disponible pour l'IA. Vous pouvez continuer à travailler pendant ce temps — les documents deviennent disponibles automatiquement dès qu'ils sont prêts. Si le traitement d'un fichier échoue, vous pouvez relancer l'opération depuis son menu d'actions.

## Documents actifs et inactifs

Chaque document dispose d'un interrupteur actif/inactif. Seuls les documents actifs sont utilisés comme contexte par l'IA. Les documents inactifs restent dans la base de connaissances mais sont exclus du chat et de la revue en grille.

C'est utile lorsque vous souhaitez restreindre l'attention de l'IA à un sous-ensemble spécifique de fichiers — par exemple, lors d'une phase d'un dossier où seuls certains contrats sont pertinents.

## Dossiers et étiquettes

Vous pouvez organiser les documents avec des dossiers et des étiquettes à code couleur.

Les **dossiers** vous permettent de reproduire votre arborescence de fichiers existante. Créez des dossiers imbriqués, déplacez des documents entre eux et téléchargez un dossier entier en ZIP lorsque vous devez partager des fichiers en dehors de Saga. L'état déplié/replié de vos dossiers est enregistré automatiquement et conservé d'une visite à l'autre, de sorte que vous retrouvez toujours l'affichage que vous aviez laissé.

Les **étiquettes** fonctionnent indépendamment des dossiers. Attribuez une étiquette à un document, donnez-lui une couleur et utilisez le filtre par étiquette pour n'afficher que les documents portant ce label. Les étiquettes sont utiles pour marquer les types de documents, l'état de la revue ou tout autre critère transversal à votre arborescence.

## Aperçu des fichiers

Vous pouvez prévisualiser certains types de fichiers directement dans le panneau latéral sans les télécharger. Cliquez sur un document dans la base de connaissances ou sur une citation dans le chat pour l'ouvrir.

| Type de fichier | Comportement de l'aperçu                                                          |
| --------------- | ---------------------------------------------------------------------------------- |
| Images          | Les fichiers PNG, JPG, JPEG, GIF, WEBP et TIFF s'ouvrent dans une visionneuse d'images avec des contrôles de zoom. Cliquez sur le bouton de réinitialisation pour revenir à la taille d'origine. |
| CSV             | Les fichiers CSV s'affichent sous forme de tableau avec des colonnes étiquetées et des lignes numérotées. Vous pouvez zoomer et dézoomer pour ajuster l'affichage. |
| Texte brut      | Les fichiers TXT sont affichés avec leur mise en forme d'origine préservée.         |
| PDF et DOCX     | Ceux-ci continuent de s'ouvrir dans le lecteur de documents intégré avec navigation par page et mise en surbrillance des citations. |

Pour les fichiers CSV et texte brut volumineux, seule une partie du contenu est affichée. Une bannière en bas vous indique que l'aperçu est tronqué — téléchargez le fichier pour voir l'intégralité du contenu.

## Actions sur les documents

Chaque document dispose d'un menu d'actions permettant de le renommer, de le déplacer vers un autre dossier, de gérer ses étiquettes, de le télécharger, de relancer le traitement ou de le supprimer. Vous pouvez également sélectionner plusieurs documents à la fois pour un téléchargement ou une suppression groupés.

Lors de la sélection de documents, les cases à cocher des dossiers affichent un indicateur de sélection partielle si seuls certains fichiers du dossier sont sélectionnés, ce qui permet de voir précisément ce qui est inclus. L'activation ou la désactivation d'un document individuel affiche l'indicateur de chargement uniquement sur cet élément, vous permettant de continuer à travailler avec le reste de la liste.
