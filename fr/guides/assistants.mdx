---
title: Vue d'ensemble
---

Chaque conversation dans Saga est alimentée par un assistant — l'IA avec laquelle vous échangez. Certains assistants sont des modèles polyvalents utilisables pour tout. D'autres sont des assistants personnalisés conçus pour des tâches spécifiques, avec des instructions déjà intégrées. Comprendre la différence vous aide à choisir le bon et à obtenir de meilleurs résultats plus rapidement.

## Le sélecteur d'assistant

Le sélecteur d'assistant apparaît en bas de la zone de saisie du chat. Cliquez dessus pour ouvrir un panneau avec deux catégories :

- **Auto** — permet à Saga de sélectionner automatiquement le meilleur modèle pour chaque message en fonction de la complexité de la tâche. Apparaît comme première option dans le sélecteur. Voir [Mode Auto](/guides/assistants/models#auto-mode) pour plus de détails.
- **Modèles** — les systèmes d'IA sous-jacents (GPT, Claude, Mistral et d'autres). Ce sont des outils polyvalents : pas de comportement préconfiguré, pas d'instructions intégrées. Vous travaillez directement avec le modèle.
- **Assistants personnalisés** — des assistants IA construits par-dessus un modèle avec des instructions structurées qui façonnent leurs réponses. Ils ont un nom, une description et un objectif défini — comme un assistant de revue de contrats ou un assistant d'audit juridique.

Survolez n'importe quelle option pour voir ses détails : une description, des indicateurs de capacité (rapidité, intelligence, capacité) et, pour les assistants personnalisés, le modèle sur lequel il est construit.

## Quand utiliser lequel

Si un assistant personnalisé correspond à votre tâche, commencez par là. Il donnera généralement de meilleurs résultats car les instructions sont déjà calibrées — l'IA sait quoi chercher, comment structurer sa réponse et pour qui elle écrit. Vous passez directement au travail sans phase de configuration.

Si votre tâche ne correspond à aucun assistant disponible, ou si vous souhaitez un contrôle total sur la conversation sans comportement prédéfini, choisissez un modèle directement. Les modèles sont le bon choix pour les questions ouvertes, l'analyse exploratoire ou tout ce qui ne correspond pas à un workflow standard.

## Paramètres par défaut

Vous n'êtes pas obligé de choisir un assistant à chaque fois que vous démarrez un chat. Saga utilise un système de valeurs par défaut à plusieurs niveaux :

- **Valeur par défaut de l'espace de travail** — définie par votre administrateur, s'applique à tous sauf si elle est remplacée
- **Valeur par défaut de l'utilisateur** — définie par vous dans **Paramètres > Personnalisation**, remplace la valeur par défaut de l'espace de travail
- **Valeur par défaut du projet** — définie par projet dans les paramètres du projet, s'applique à tous les nouveaux chats de ce projet

La valeur la plus spécifique l'emporte. Si vous avez défini une valeur par défaut utilisateur, c'est celle que vous obtenez dans les chats globaux. Si un projet a sa propre valeur par défaut, elle prend la priorité dans ce projet. Vous pouvez toujours remplacer n'importe quelle valeur par défaut en sélectionnant un assistant différent dans le sélecteur.

## Changer d'assistant en cours de conversation

Vous pouvez changer d'assistant entre les messages. Cliquez sur le sélecteur d'assistant et choisissez-en un autre — le nouvel assistant s'applique à partir de ce point. Les messages précédents de la conversation restent inchangés.

C'est utile lorsque vous commencez avec un modèle général pour explorer une question, puis passez à un assistant spécialisé une fois que vous savez quel type d'analyse vous avez besoin. Ou lorsque vous souhaitez comparer comment deux modèles différents traitent le même prompt — envoyez le message, changez de modèle et régénérez.
