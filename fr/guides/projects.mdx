---
title: Vue d'ensemble
---

Un projet est votre espace de travail pour un dossier, une transaction ou tout autre ensemble de travaux. Il centralise tout — les documents sur lesquels vous travaillez, les conversations IA que vous avez eues et les revues structurées que vous avez effectuées. Lorsque vous posez une question à l'IA dans un projet, elle s'appuie automatiquement sur les documents de ce projet.

## Créer un projet

Cliquez sur **Projets** dans la barre latérale, puis sur **Nouveau projet**. Donnez-lui un nom qui identifie le dossier — un nom d'affaire, une référence client ou un nom de transaction convient bien.

Vous pouvez également configurer quelques paramètres optionnels dès le départ :

- **Description** — une courte note affichée sur la carte du projet, utile lorsque vous avez de nombreux projets. Cliquez sur **Générer avec l'IA** si vous voulez que Saga la rédige à partir du nom du projet.
- **Assistant par défaut** — le modèle IA ou l'assistant personnalisé qui s'ouvre par défaut pour les nouveaux chats dans ce projet
- **Tags** — libellés affichés sur la carte du projet et dans les filtres de la liste
- **Date d'échéance** — une date facultative sur la carte pour repérer le travail à venir. À côté de la date d'échéance, la carte indique quand le projet a été mis à jour pour la dernière fois, par exemple « Mis à jour aujourd'hui ». L'icône du calendrier change lorsque le projet arrive à échéance dans les sept prochains jours, et devient rouge lorsque la date d'échéance est dépassée.
- **Instructions personnalisées** — un contexte permanent qui s'applique à chaque interaction IA dans le projet, comme « Ce dossier concerne le droit du travail néerlandais » ou « Répondez toujours en norvégien »

Vous pouvez modifier ces paramètres à tout moment depuis le menu des paramètres du projet.

Sur la page **Projets**, utilisez **Trier** et **Filtrer** pour trouver un projet par tag, date d'échéance, statut ou personnes. Les projets archivés restent hors de la liste par défaut jusqu'à ce que vous les incluiez dans le filtre.

Pour changer l'affichage de vos projets, cliquez sur le sélecteur de vue à côté de **Filtrer**, puis choisissez **Vue cartes** ou **Vue liste**. La **Vue liste** affiche une ligne par projet, avec les colonnes **Projet**, **Statut**, **Membres**, **Étiquettes** et **Date d’échéance**. Cliquez sur une ligne pour ouvrir le projet, ou utilisez le menu **...** en fin de ligne. Saga retient la vue choisie dans ce navigateur. La vue par défaut est **Vue cartes**.

## Contenu d'un projet

Chaque projet comprend les onglets **Discussion** et **Aperçu**. Ces deux onglets affichent une icône de cadenas, car vous ne pouvez pas les retirer. Un nouveau projet ne comprend au départ que ces deux onglets.

Pour ajouter un onglet, comme **Revue de grille**, cliquez sur **+** (**Ajouter un onglet**) à côté des onglets et choisissez l'onglet. L'onglet s'ouvre aussitôt. Les onglets d'un projet sont partagés : un onglet que vous ajoutez apparaît pour tous les membres du projet. Les membres disposant d'un accès **Lecture seule** ne peuvent pas ajouter d'onglets.

Chaque onglet que vous pouvez retirer dispose d'un menu **...** :

- **Masquer l’onglet** masque l'onglet pour vous seulement. Les autres membres le voient toujours. Pour l'afficher à nouveau, cliquez sur **+** et choisissez l'onglet marqué **Masqué**.
- **Retirer de ce projet** retire l'onglet pour tous les membres du projet. Saga vous demande d'abord de confirmer. Les membres disposant d'un accès **Lecture seule** ne voient pas cette option. Si vous ajoutez de nouveau l'onglet plus tard, son contenu est rétabli.

Faites glisser les onglets pour les placer dans l'ordre de votre choix. Saga enregistre cet ordre pour vous dans ce projet : il reste le même après un rechargement et sur vos autres appareils. Les autres membres conservent leur propre ordre.

L'onglet **Vue d'ensemble** affiche l'activité récente du projet, comme les imports, les chats, les revues en grille, les modifications de partage et les événements similaires, dans un fil où les éléments les plus récents apparaissent d'abord. Il inclut aussi un panneau d'informations du projet en lecture seule. Vous pouvez filtrer le fil par catégorie et ouvrir les éléments liés lorsqu'ils sont encore disponibles.

L'onglet **Chat** est l'endroit où vous menez des conversations IA dans le contexte du projet. Vous pouvez ouvrir le panneau de la base de connaissances à tout moment en cliquant sur **Afficher la base de connaissances**, afin de gérer les fichiers et poser des questions dans la même vue.

L'onglet **Revue en grille** est l'endroit où vous effectuez des revues structurées de documents. Définissez un ensemble de questions, sélectionnez les documents, et l'IA analyse chacun d'eux en fonction de vos questions dans un format tabulaire.

Les onglets Chat et Revue en grille s'appuient sur la même base de connaissances, de sorte que tout document importé est disponible aussi bien dans le chat que dans la revue en grille.

## Personnaliser un projet

La description, l'assistant par défaut et les instructions personnalisées déterminent le comportement de l'IA dans un projet. Vous pouvez les définir à la création du projet ou les ajouter plus tard (voir Modifier un projet).

Les instructions personnalisées ont le plus d'impact. Il s'agit d'un contexte permanent appliqué à chaque interaction IA dans le projet, pour ne pas répéter les mêmes informations à chaque nouveau chat. De bonnes instructions énoncent des faits sur le dossier et des préférences pour les réponses :

- Juridiction et domaine du droit, comme « Ce dossier concerne le droit du travail néerlandais »
- Langue et style, comme « Répondez toujours en norvégien » ou « Restez concis »
- Contexte que l'IA doit connaître, comme les parties, les dates clés ou les termes définis

Les instructions s'appliquent uniquement au sein du projet. Restez factuel et précis : plus elles décrivent précisément le dossier, plus chaque réponse gagne en pertinence.

## Modifier un projet

Ouvrez le projet, cliquez sur le menu **...** dans l'en-tête et sélectionnez **Modifier le projet**. Vous pouvez mettre à jour le nom, la description, l'assistant par défaut et les instructions personnalisées à tout moment.

## Supprimer un projet

Ouvrez le menu **...** et sélectionnez **Supprimer le projet**. La suppression est définitive — elle efface tous les documents, chats et revues en grille du projet. Si le projet est partagé, les collaborateurs perdent immédiatement l'accès.
