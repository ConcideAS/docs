---
title: Style des documents
description: Configurez la manière dont les exports Word générés par Saga suivent le style documentaire de votre cabinet.
---

Le style des documents est un paramètre administrateur pour les exports Word générés par Saga. Utilisez-le lorsque votre cabinet souhaite que les brouillons, résumés, notes ou autres documents générés par l'IA suivent les mêmes polices, mises en page, en-têtes, pieds de page et numérotation.

Seuls les administrateurs peuvent configurer le style des documents. Les utilisateurs voient le résultat lorsqu'ils exportent du contenu généré après l'enregistrement des paramètres.

## Ce que contrôle le style des documents

Le style des documents peut contrôler :

- Police, taille, couleur et interligne du corps de texte
- Polices, tailles, couleurs et graisse des titres
- Format de page, orientation, marges, retraits et espacements
- Texte d'en-tête et de pied de page
- Position et alignement des numéros de page
- Logos dans les en-têtes et pieds de page

Ces paramètres s'appliquent aux nouveaux exports. Ils ne modifient pas les fichiers déjà téléchargés ni les documents que les utilisateurs importent dans un projet ou une base de connaissances.

## Importer un document de référence

Utilisez un document de référence lorsque vous disposez déjà d'un fichier Word qui représente le style de votre cabinet.

1. Ouvrez le **Panneau d'administration**.
2. Accédez à **Style des documents**.
3. Importez un document de référence `.docx`.
4. Vérifiez le style extrait dans l'aperçu.
5. Ajustez les champs manuellement si nécessaire.
6. Cliquez sur **Enregistrer les modifications**.

<Tip>
Utilisez un document de référence propre avec les styles que vous souhaitez que Saga copie. Évitez les documents avec suivi des modifications, titres incohérents ou mise en forme inhabituelle ponctuelle.
</Tip>

## Ajuster et tester le style

Vous pouvez affiner le style extrait avant de l'enregistrer ou configurer le style manuellement. Les modifications s'appliquent aux nouveaux exports après leur enregistrement. Exportez un court document de test depuis le chat et vérifiez dans Word le corps de texte, les titres, les marges, les en-têtes, les pieds de page, les numéros de page et les logos.
