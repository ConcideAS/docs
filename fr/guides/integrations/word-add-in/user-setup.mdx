---
title: Installation utilisateur
---

L'installation du complément Saga pour Word prend quelques minutes. Il y a deux façons de procéder — depuis Word ou depuis le Microsoft Marketplace. Si votre organisation le déploie de manière centralisée, il est peut-être déjà installé (voir [Installation administrateur](/fr/guides/integrations/word-add-in/admin-setup)).

## Installer depuis Word

**Windows (Microsoft 365 / Word 2021 / 2024) :**
1. Ouvrez Word et cliquez sur **Compléments** dans le ruban, puis **Plus de compléments**.
2. Recherchez **Saga** dans le Store de compléments Office.
3. Cliquez sur **Ajouter**.

**Windows (Word 2019 / 2016) :**
1. Allez dans **Insertion > Obtenir des compléments** (ou **Store**).
2. Recherchez **Saga**.
3. Cliquez sur **Ajouter**.

**Mac :**
1. Allez dans **Insertion > Obtenir des compléments**.
2. Recherchez **Saga**.
3. Cliquez sur **Ajouter**.

**Word pour le Web :**
1. Ouvrez un document dans Word pour le Web (via office.com ou OneDrive).
2. Allez dans **Insertion > Compléments > Obtenir des compléments**.
3. Recherchez **Saga**.
4. Cliquez sur **Ajouter**.

Après l'installation, le complément Saga apparaît dans l'onglet **Accueil** ou **Insertion** du ruban.

## Installer depuis le Microsoft Marketplace

Vous pouvez également l'installer directement depuis le [Microsoft AppSource Marketplace](https://marketplace.microsoft.com/en-us/product/saas/wa200009415?tab=overview) :

1. Ouvrez le lien et cliquez sur **Obtenir maintenant**.
2. Connectez-vous avec votre compte Microsoft si demandé.
3. Suivez les instructions à l'écran pour ajouter le complément à Word.

## Connexion

Lorsque vous ouvrez le complément pour la première fois, saisissez votre **adresse e-mail** et l'**URL Saga** de votre organisation (par ex., `https://votre-cabinet.sagalegal.io`). Saga vous envoie un lien magique — cliquez dessus pour confirmer, et le complément se connecte à votre compte. Vous ne devez le faire qu'une seule fois.

## Dépannage

Si le complément n'apparaît pas dans les résultats de recherche ou ne parvient pas à s'installer :

- **Vérifiez auprès de votre administrateur** — Sur les appareils gérés par l'entreprise, votre service informatique peut avoir besoin d'autoriser les compléments Office tiers ou d'approuver explicitement le complément Saga.
- **Vérifiez votre licence Office** — Certaines éditions en licence en volume (LTSC) ont un accès limité au Store de compléments Office. Votre administrateur peut avoir besoin de [déployer le complément de manière centralisée](/fr/guides/integrations/word-add-in/admin-setup).
- **Vérifiez votre connexion** — Dans Word, allez dans **Fichier > Compte** et assurez-vous d'être connecté avec votre compte Microsoft.
- **Vérifiez votre version de Word** — Allez dans **Fichier > Compte > À propos de Word** et assurez-vous que votre version est à jour. Les versions obsolètes peuvent avoir des problèmes de chargement de compléments.

Si le problème persiste, contactez l'équipe de support Saga avec une capture d'écran des informations de version de Word (**Fichier > Compte > À propos de Word**) et tout message d'erreur rencontré.
