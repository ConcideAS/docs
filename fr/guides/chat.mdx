---
title: Vue d'ensemble
---

Le chat est l'endroit où vous travaillez avec l'IA dans Saga. Posez des questions sur vos documents, rédigez du contenu, analysez des éléments ou lancez des recherches — le tout au travers d'une conversation en langage naturel. L'IA s'appuie sur le contexte que vous lui fournissez et cite ses sources pour que vous puissiez vérifier chaque réponse.

## Démarrer une conversation

Cliquez sur **Chat** dans la barre latérale pour ouvrir une nouvelle conversation. Saisissez votre question et appuyez sur **Entrée** pour l'envoyer.

Vous pouvez également démarrer un chat depuis un projet. Dans ce cas, l'IA a automatiquement accès à la base de connaissances de ce projet — chaque document actif devient un contexte pour la conversation sans que vous ayez besoin de joindre quoi que ce soit.

## Fonctionnement du contexte

Les réponses de l'IA dépendent des informations auxquelles elle a accès. Dans un **chat de projet**, ce contexte provient de la base de connaissances du projet. Dans un **chat global** (en dehors de tout projet), vous fournissez le contexte en joignant des fichiers, en sélectionnant des sources organisationnelles ou en activant la recherche web. Vous pouvez également combiner plusieurs sources dans une même conversation.

Pour une explication complète de la gestion du contexte de l'IA, consultez [Contexte et sources](/fr/guides/chat/context-and-sources).

## Citations

Lorsque l'IA fait référence à un document, elle inclut des citations en ligne — de petites pastilles numérotées liées au passage précis dont elle s'est servie. Survolez une citation pour voir l'extrait original. Cliquez dessus pour ouvrir le document source dans le panneau latéral, directement à la section concernée.

Les citations fonctionnent pour les documents de projet, les résultats de recherche juridique et les sources web. Elles vous permettent de vérifier ce que l'IA vous indique sans avoir à chercher manuellement dans les fichiers.

## Actions sur les messages

Survolez n'importe quel message pour voir les actions disponibles :

- **Copier** le contenu du message dans le presse-papiers
- **Régénérer** une nouvelle réponse à la même question
- **Exporter vers Word** pour télécharger le message au format .docx
- **Modifier** votre message original pour obtenir une réponse révisée
- **J'aime / Je n'aime pas** pour donner votre avis sur la qualité de la réponse
- **Enregistrer dans la bibliothèque de prompts** pour réutiliser un prompt que vous avez rédigé
- **Supprimer** le message de la conversation

## Versions des messages

Lorsque vous modifiez un message ou régénérez une réponse, Saga crée une nouvelle version au lieu d'écraser l'originale. Des flèches de navigation apparaissent pour vous permettre de passer d'une version à l'autre.

C'est utile lorsque vous souhaitez explorer différents angles sur la même question — par exemple, demander à l'IA d'analyser une clause selon deux juridictions différentes, ou reformuler une question pour voir si un cadrage plus large ou plus étroit donne de meilleurs résultats. Chaque version est conservée, vous pouvez donc toujours revenir en arrière.

## Tâches

Les tâches sont des commandes intégrées pour les opérations courantes. Accédez-y depuis le bouton **Tâches** dans la barre d'outils du chat ou en tapant `/` dans le champ de saisie :

| Tâche | Ce qu'elle fait |
|------|-------------|
| `/summarize` | Génère un résumé concis du texte ou des documents fournis |
| `/anonymize` | Supprime les identifiants personnels et les informations sensibles |
| `/proofread` | Vérifie la grammaire, l'orthographe et le style du texte |
| `/compare` | Compare deux textes ou sections de documents et met en évidence les différences |

Sélectionnez une tâche dans le menu déroulant, puis fournissez le texte ou les documents à traiter.

## Améliorer le prompt

Avant d'envoyer un message, cliquez sur l'icône du stylo à côté du bouton d'envoi pour laisser l'IA affiner votre prompt. Cela peut vous aider à obtenir des résultats plus ciblés, en particulier pour les questions complexes. Si vous préférez votre texte original, cliquez sur la flèche de retour pour annuler l'amélioration.

## Saisie vocale

Cliquez sur l'icône du microphone dans le champ de chat pour dicter votre message au lieu de le taper. Saga transcrit ce que vous dites dans le champ de saisie, où vous pouvez le modifier avant de l'envoyer. L'enregistrement est limité à trente minutes par session et nécessite l'accès au microphone dans votre navigateur.

## Mode réflexion

Certains modèles affichent leur raisonnement étape par étape dans une section dépliable avant la réponse finale. C'est utile pour les questions juridiques complexes où vous souhaitez voir comment l'IA est parvenue à sa conclusion. Si vous n'avez pas besoin du raisonnement, cliquez sur **Passer la réflexion pour une réponse plus rapide** pour obtenir une réponse directe.

## Quand l'IA a besoin d'une décision

Si une demande est ambiguë au point de changer le travail, l'IA peut s'interrompre et vous poser une question structurée plutôt que de deviner. La question remplace la zone de saisie jusqu'à votre réponse.

Choisissez l'une des options proposées, ou saisissez une courte réponse. Utilisez **Ignorer** si vous voulez que l'IA continue sans cette décision. Après l'envoi, la saisie normale réapparaît. Les questions répondues restent dans le fil sous forme de résumé compact ; les questions ignorées restent marquées comme ignorées.

## Exporter une conversation

Pour télécharger un chat entier sous forme de document Word, cliquez sur le bouton d'export dans l'en-tête du chat. L'export inclut tous les messages, les citations et le titre de la conversation. Vous pouvez également exporter des messages individuels depuis le menu d'actions du message.

## Documents générés par l'IA

Lorsque l'IA rédige un document — tel qu'une note, un résumé ou une clause contractuelle — il apparaît sous forme de pastille sous la réponse. Cliquez sur la pastille pour ouvrir le document dans le panneau latéral. Survolez-la et cliquez sur l'icône de téléchargement pour l'exporter au format Word.

## Modifier un document avec l'IA

Vous pouvez réécrire un passage d'un document généré par l'IA sans tout recommencer. Ouvrez le document depuis sa pastille, sélectionnez le texte, puis cliquez sur **Insert to Chat**. La sélection apparaît sous forme de carte dans le champ de saisie. Décrivez le changement et envoyez. Saga crée une nouvelle version du document avec cette section mise à jour.

Vous pouvez ajouter jusqu'à cinq sélections de la même version du document et les modifier avec une seule instruction. Cliquez plus tard sur une carte pour rouvrir le document avec ce passage surligné.

Les sélections qui contiennent un tableau ne peuvent pas encore être modifiées avec l'IA. Les sélections qui se chevauchent, une sixième sélection ou du texte provenant d'une autre version du document sont bloquées. Retirez les fichiers joints, une tâche ou un workflow sélectionné du message avant d'insérer du texte.

## Historique des chats

Vos conversations sont enregistrées dans l'historique des chats, accessible depuis la barre latérale. Vous pouvez rechercher des chats par titre, ajouter des favoris pour un accès rapide, renommer des conversations ou les supprimer. L'historique des chats est organisé avec les favoris en premier, puis par activité la plus récente.

## Limites de contexte

Si une conversation approche la limite de contexte de l'IA, un avertissement s'affiche pour vous indiquer que le chat est presque plein. Dans ce cas, démarrez une nouvelle conversation ou créez un projet avec une base de connaissances pour donner à l'IA un contexte documentaire plus large.
